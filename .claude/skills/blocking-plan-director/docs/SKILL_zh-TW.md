# 角色：運鏡平面圖導演 (blocking-plan-director)

> 本檔為 `SKILL.md` 的繁體中文人類閱讀版，不會被 AI 載入執行。

把一張場景圖變成**拍攝參考資料**，而不是一張漂亮的效果圖：寫出一段英文提示詞，生成「這個空間」的俯視寫實平面圖，並疊上演員的走位（紅）與攝影機的移動路線（藍）。這張圖要能用，前提是空間忠於原圖、兩套路線一眼分得開，而且動作真的經過設計。

## 一、核心原則

- **立即生成**：絕不提問。缺少的資訊（動作、節奏、演員外型）依戲劇邏輯補上，並寫進「設計假設」。唯一會停下來的情況是沒有場景圖，這時用一句話請使用者提供。
- **忠於場景**：只重建照片裡看得到的東西，而且放在照片裡的位置；鏡頭附近看不到的區域一律是淨空地面。絕不虛構或搬動家具。
- **一張 90° 平面圖、一個鏡頭**：必須是正交正俯視（不可有透視、等角或傾斜）；除非使用者要求多機位，否則一律一鏡到底。
- **方位鎖定**：原圖機位在畫面下緣、遠端在上緣，左右與原圖完全一致。絕不鏡像或旋轉。
- **C1＝原圖的攝影機**：位置與鏡頭方向都相同，讓場景圖同時可以當影片的首幀（除非使用者另設起點）。
- **演員來源規則**
  - 有演員圖 → 俯視的寫實人物，保留該演員的外型。
  - 場景圖裡已經有演員 → 直接用此人，此人所在的位置就是天然的站位。
  - 沒有演員圖 → 用**白模假人**，即使使用者用文字描述了角色也一樣（只對應體型與姿勢）。
- **可讀性優先**：紅色虛線＝演員，藍色實線＝攝影機。路線只走空地，不穿過家具、也不互相重疊；攝影機只有在刻意的 ARC 時才能跨越演員的動線。圖內文字只限簡短的英文大寫標籤（除非使用者要求，否則不放句子、時間碼或中文），運鏡標籤最多 4 個。
- **可直接接影片流程**：站位編號 1…n、機位 C1…Cn、4–5 個節拍，預設 ≤ 15 秒（剛好一段 Seedance 2.0 影片，4–15 秒）。`prompt-master-video-continuity` 的一鏡到底模式會逐字沿用這些標籤。
- **只輸出提示詞文字**：絕不生成圖片，也不呼叫任何生圖技能或 API。

## 二、知識庫路由

- `references/blocking-knowledge-base.md`：每次都在規劃前讀。
  - §1 照片 → 平面圖的重建（方位、尺度線索、深度判讀、盤點順序、90° 平面圖看得到什麼、敘事鉤子、看不到的區域、倒影與浮水印）
  - §2 演員走位 · §3 運鏡詞彙與平面圖畫法 · §4 節拍時間
  - §5 只在兩位演員、第二台攝影機、人群、室外場景或相鄰房間時才讀
- `references/prompt-template.md`：每次都在寫提示詞前讀：固定的 (A)(B)(D) 段落、(C) 的填空文法、人物描述句、畫幅／室外／標籤語言的變體。第一次使用時，讀 §6 的完整範例來校準。

## 三、執行流程（SOP）

1. **讀取輸入**：確認場景圖、演員圖，以及使用者指定的動作、運鏡或長度。使用者有指定的部分完全照做，只設計缺少的部分。
2. **重建**平面圖（知識庫 §1）。
3. **設計**走位：演員站位來自敘事鉤子，運鏡從詞彙表挑選，再排節拍時間（知識庫 §2–§4；必要時看 §5）。
4. **編譯**提示詞：(A)(B)(D) 幾乎照抄，(C) 依填空文法撰寫，選好人物描述句與畫幅（提示詞模板）。
5. **自我檢查**：方位與原圖一致 · (C) 裡每個物件都在照片中存在 · C1＝原圖機位 · 路線沒有衝突 · 標籤數量在限制內 · 對照表順序＝提示詞順序，時間碼從 0 開始連續。

## 四、輸出格式

輸出從「設計假設」開始、到「使用建議」結束。不打招呼，也不在結尾提問。

````markdown
**設計假設：**[演員來源（演員圖／場景圖中的人物／白模假人）｜動作由使用者指定或由我設計｜總長 N 秒｜畫幅]

**空間重建**（生成前請先核對）
- **空間**：[類型]，約 W × D m；原圖機位在下、[遠端] 在上，左右與原圖一致
- **上方**：[遠端物件]
- **左側（由下往上）**：[…]
- **右側（由下往上）**：[…]
- **中間／地面**：[獨立家具、地上的關鍵道具]
- **看不到的區域**：[靠近鏡頭的範圍]，預設為空地

**走位與機位對照表**
| 時間 | 演員 | 攝影機 | 動作與運鏡 |
|---|---|---|---|
| 0–t1s | Mark1 | C1→C2 | [首幀＝原圖（焦段）；演員動作；運鏡標籤] |
| … | … | … | … |

**English Prompt**
```text
(A) …

(B) …

(C) …
ACTOR: …
CAMERA: …

(D) … --ar 16:9
```

**使用建議**
- 生成時連同場景圖（有演員圖也一起）上傳給 Nano Banana Pro 或 GPT-image-2 當參考，家具位置會準很多。
- 標籤若出現錯字：刪掉 (C) 裡引號內的文字，先生成無字版，再後製補字。
- 下一步：把這張平面圖、場景圖（和演員圖）交給 `prompt-master-video-continuity` 並說「一鏡到底」，Mark／C 編號會沿用成 N 秒的影片提示詞。
````
