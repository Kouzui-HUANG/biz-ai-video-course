## 一、空間重建（照片 → 平面圖）

### 1.1 方位
- 原圖機位 → **畫面下緣**。與成像平面最平行的那面牆或邊界 → **上緣**。左右維持照片原樣，絕不鏡像。
- 兩點透視（對著牆角拍）的照片：牆面仍與畫面軸線對齊；把 C1 放在攝影機那一側的下方角落，斜向對準它面對的牆角。
- 鏡頭高度＝地平線：頂端剛好碰到地平線的物件，高度就等於攝影機高度。
- 焦段：看地面線條收斂得多快來估（收斂強烈 ≈ 18–24 mm，中等 ≈ 35 mm，平緩 ≈ 50 mm 以上）。焦段寫在對照表裡，不放在圖上。

### 1.2 尺度線索（W × D 估到最接近的 0.5 m）
| 線索 | 常見尺寸 |
|---|---|
| 門扇 | 高 2.0–2.1 m，寬 0.8–0.9 m |
| 天花板 | 現代住宅 2.4–2.8 m；古典／奧斯曼／挑高 loft 3.0–3.6 m |
| 流理台 · 餐桌 | 高 0.9 m · 高 0.75 m、深 0.8–1.0 m |
| 椅面 · 沙發 | 高 0.45 m · 長 2.0–2.4 m |
| 床 · 直立鋼琴 · 平台鋼琴 | 長 2.0 m · 寬 1.5 m · 長 1.5–2.7 m |
| 地磚 | 30／45／60 cm，數磚塊就能量距離 |
| 成人 · 汽車 | 1.6–1.8 m · 長 4.5 m |
| 人行道 · 車道 | 寬 1.5–3 m · 寬 3–3.5 m |

### 1.3 從單張照片判讀深度
- 地面上的接地點在畫面中越低，離攝影機越近。
- 沿著側牆，越靠近畫面中央的物件離得越遠。
- 磚縫、地毯、木地板就是格線；數格子即可定位物件。

### 1.4 盤點順序（對應 (C) 段落）
形狀、尺寸、方位 → 從上方看的地面材質與紋樣 → 上緣 → 左側（由下往上）→ 右側（由下往上）→ 以固定物件為錨點的獨立家具（例如「壁爐與棕櫚之間、離牆約一公尺」）→ 地上的道具／敘事鉤子 → 天花板上的燈具 → 看不到的區域。

### 1.5 90° 平面圖看得到、看不到什麼
- 正上方看不到：牆上的畫、鏡子、壁燈、窗簾的正面。只有走位用得到時才提，並畫成牆上的一條細線。
- 懸在空中的物件（吊燈、垂吊燈、吊扇、橫樑）：用細的灰色虛線輪廓表示。
- 陽台、窗台、門的開啟弧線都看得清楚，要寫進描述。
- 室外：樹冠與遮雨棚畫成半透明，讓下方的路線保持可見。

### 1.6 敘事鉤子
暗示動作或故事的道具：被留下的鞋、攤開的信、樂器、鏡子、窗外的景、沒整理的床、喝到一半的杯子、半開的門。挑出 2–4 個，它們就是站位。

### 1.7 看不到的區域
鏡頭附近、畫面邊緣以外的區域是未知的，一律描述成淨空的地面。除非使用者有說明，否則絕不在那裡擺家具。

### 1.8 照片上的干擾
- 鏡子、玻璃牆面、窗戶或亮面地板裡的倒影，照到的是攝影機後方或牆後的空間。倒影中的物件絕不放進平面圖；除非使用者確認，看不到的區域仍維持淨空。
- 忽略照片上的浮水印、商標、圖說與介面疊字。

## 二、演員走位設計

### 2.1 使用者有指定動作
把每個描述到的動作依序對應到一個站位，保留使用者用的動詞。只補缺口：精確位置、路線形狀、時間。

### 2.2 從零開始設計
預設弧線：**進場 → 靠近一個鉤子 → 停在光源或景觀前 → 落在最強的鉤子**（坐下、跪下、觸碰、拾起）。
- 3–5 個站位。第一個站位放人物。
- 從畫面外或畫面邊緣起步，讓場景圖維持是首幀。
- 路線形狀要好讀：S 形、Z 形或 L 形；不能自己交叉；一律走空地。
- 每個站位都綁在一個固定地標上（「紅椅旁」「中央落地窗前」）。
- 如果場景圖裡有演員，此人所在的位置就是 Mark 1 或關鍵站位。

### 2.3 畫法
- 行走：深紅色虛線加箭頭。站位：編號紅色圓圈。
- 轉身：站位上的小弧形箭頭。離場：箭頭穿過門或畫面邊緣，離開平面圖。
- 姿勢（坐、跪、躺）用文字寫在該站位；只有放人物的那個站位會顯示姿勢。

## 三、運鏡詞彙與平面圖畫法

| 運鏡 | 標籤 | 畫法 |
|---|---|---|
| 固定／停住 | HOLD | 只有圖示，沒有延伸出去的路線 |
| 搖鏡 | PAN LEFT / PAN RIGHT | 圖示＋小的旋轉弧形箭頭＋兩個扇形（起始淡、結束實） |
| 俯仰 | TILT UP / TILT DOWN | 標籤放在圖示旁（垂直運動，平面圖上看不到） |
| 推軌前進 | DOLLY IN | 沿鏡頭軸線朝主體前進的直線段 |
| 拉遠 | PULL BACK | 沿鏡頭軸線往後退的直線段 |
| 橫移 | TRUCK LEFT / TRUCK RIGHT | 側向直線段；扇形保持平行 |
| 軌道跟拍 | TRACKING | 與演員路線平行、帶細軌枕刻線的線段 |
| 穩定器跟拍 | STEADICAM FOLLOW | 在演員身後 1.5–3 m 跟隨的平滑曲線 |
| 手持 | HANDHELD | 微微起伏的線 |
| 弧線／環繞 | ARC 90° / ORBIT 360° | 繞著主體的圓弧段，角度寫在標籤裡 |
| 升降臂／搖臂 | CRANE UP / CRANE DOWN | 標籤＋圖示旁的小垂直箭頭 |
| 變焦 | ZOOM IN / ZOOM OUT | 沒有路線；一寬一窄的套疊扇形 |
| 滑動變焦 | DOLLY ZOOM | 直線段＋標籤 |
| 甩鏡 | WHIP PAN | 圖示＋銳利的弧形箭頭 |
| 空拍機 | DRONE | 點線路線＋標籤 |

攝影機規則：
- C1＝原圖機位。3–5 個機位；有標籤的運鏡最多 4 個。
- 逐步升級：靠近（DOLLY IN）→ 陪伴（STEADICAM FOLLOW／TRACKING／TRUCK）→ 揭示（ARC／PULL BACK／CRANE）。
- 除了收尾畫面，與演員保持 1.5–3 m。走在演員路線的旁邊或後方，絕不壓在上面；只有刻意的 ARC 才能跨越演員的動線。
- 最後一個扇形要讓演員落在最有看頭的背景前（窗、光、鉤子）。

## 四、節拍時間
- 步行 ≈ 1 m/s（戲劇性的慢走 0.6–0.8 m/s）；停頓 1–3 秒；坐下／起身／跪下 ≈ 1.5 秒；拾起或觸碰 ≈ 1 秒。
- 預設總長 ≤ 15 秒（一段 Seedance 2.0 影片為 4–15 秒）。4–5 個節拍（總長 ≤ 8 秒時用 3 個）。每個節拍＝一個站位＋一個運鏡；時間碼從 0 開始連續。
- 如果使用者指定更長的鏡頭，就照使用者的長度做，並在「使用建議」註明影片必須拆成每段 ≤ 15 秒。

## 五、特殊情況
- **兩位演員**：A＝深紅（A1…），B＝琥珀橘（B1…）；各自的第一個站位放人物；白模假人的底座加一圈細的深紅或琥珀色；圖例寫「ACTOR A」「ACTOR B」「CAMERA」。一張圖最多 2 位演員，更多就拆成好幾張。
- **第二台攝影機**：藍綠色圖示，標「CAM 2」，有自己的扇形（固定機位）或自己的藍綠色路線。最多 2 台。
- **場景中的路人**：刪掉；若使用者想保留，就畫成灰色的靜止假人。
- **室外**：使用 `prompt-template.md` §5 的場地區塊替換段；車輛除非有安排走位，否則保持靜止。
- **通往其他房間的門**：只有路線會經過時，才畫出相鄰空間的一小條。
