## 一、句型卡

每張卡包含：**骨架**・**經典作**・**為什麼有效**・**最適合**・**風險 → 對策**。

### A1 條件反轉型
- **骨架：** 〜したら、〜だった（件）／〜に生まれ変わった俺は〜／轉生成〜／一覺醒來，我成了〜／~했더니 ~였다
- **經典作：** 転生したらスライムだった件・転生したら剣でした・自動販売機に生まれ変わった俺は迷宮を彷徨う
- **為什麼有效：** 前提＋意外的名詞＝立刻有畫面，也立刻有疑問：「這樣到底要怎麼活？」
- **最適合：** 異世界、轉生、靈魂互換、穿越／穿書
- **風險 → 對策：** 最泛濫的模板，名詞不夠意外就會被淹沒 → 名詞要比該類型目前熱門作品裡的任何一個都更低、更怪，而且要帶缺陷（T3）。

### A2 因果宣言型
- **骨架：** 〜されたので、〜することにしました／被〜的我，決定〜／〜後，我〜了／~당해서 ~하기로 했다
- **經典作：** 真の仲間じゃないと勇者のパーティーを追い出されたので、辺境でスローライフすることにしました・追放されたチート付与魔術師は気ままなセカンドライフを謳歌する。
- **為什麼有效：** 先給一個不公平，讓讀者憤憤不平；後面的決定預告會有回報。
- **最適合：** 追放、退婚、復仇、慢活、逆襲、中國微短劇
- **風險 → 對策：** 容易承諾違約（F4）和過長（F6）→ 決定動詞必須是核心循環；長度砍到市場上限內。

### A3 反語否認型
- **骨架：** 〜がこんなに〜わけがない／やはり〜はまちがっている。／〜のは間違っているだろうか／〜哪有這麼〜／〜才不是〜／~할 리가 없어
- **經典作：** 俺の妹がこんなに可愛いわけがない・やはり俺の青春ラブコメはまちがっている。・ダンジョンに出会いを求めるのは間違っているだろうか
- **為什麼有效：** 書名本身在演敘事者的否認，讀者卻知道事實正好相反，形成反諷、傲嬌感和熟悉類型的自嘲喜劇。
- **最適合：** 戀愛喜劇、校園、自我吐槽型喜劇
- **風險 → 對策：** 否認的對象太空泛（「人生哪有這麼難」）→ 否認一件具體、有點丟臉的事。

### A4 角色特寫型
- **骨架：** 〔頻率／習慣〕＋〔祕密癖好〕＋〔關係位置：隣の／クラスの／上司の〕＋〔名字＋敬稱〕
- **經典作：** 時々ボソッとロシア語でデレる隣のアーリャさん・弱キャラ友崎くん・政宗くんのリベンジ
- **為什麼有效：** 直接點名一個讀者會愛上的人；祕密癖好製造戲劇反諷（讀者知情）。
- **最適合：** 戀愛喜劇、日常、角色驅動的系列
- **風險 → 對策：** 癖好太普通（「很可愛的」）→ 癖好必須具體而且是祕密。

### A5 嗆聲對話型
- **骨架：** 〜ですが、なにか?／〜したいと思います。／〜又怎樣？／吃了我的〜，還想〜？／~인데요, 뭐?
- **經典作：** 蜘蛛ですが、なにか?・痛いのは嫌なので防御力に極振りしたいと思います。
- **為什麼有效：** 主角的態度在第一頁之前就先開口；態度本身變成品牌。
- **最適合：** 喜劇、強到離譜但很怪的主角、中韓短劇的鉤子
- **風險 → 對策：** 態度和黑暗或嚴肅的作品衝突 → 只有在正文的敘事口吻真的是這樣時才用。

### A6 數值・規則型
- **骨架：** Lv.／9999／SSS級／極振り／ステータス／ガチャ／〜的規則：〜／나 혼자만 ~
- **經典作：** 信じていた仲間達に…ギフト『無限ガチャ』でレベル9999の仲間達を…（無限ガチャ）・나 혼자만 레벨업・防振り
- **為什麼有效：** 讀者熟悉遊戲，數字和規則一看就懂；寫出一條規則，就會讓人想問「違反了會怎樣？」
- **最適合：** 遊戲系統、獵人、地下城、規則怪談、噱頭型短劇
- **風險 → 對策：** 數字通膨（99999…）、模板感重 → 只用一個數字或規則，而且要綁住錨點名詞。

### A7 熟語改造型
- **骨架：** 一個觀眾倒背如流的詞組，換掉其中一個元素
- **經典作：** 전지적 독자 시점（← 전지적 작가 시점，文學術語「全知作者視角」）・（示意）炸後吐真言（← 酒後吐真言）
- **為什麼有效：** 熟悉感＋錯位感，是最好記的短形式；通常短到本身就能當略稱。
- **最適合：** 各類型皆可；放在短名／品牌名的位置最強
- **風險 → 對策：** 原詞在該市場不普及或無法翻譯 → 選該語言每個讀者都知道的詞組；每個外銷市場另做一個改造版。

### A8 雅名型
- **骨架：** 〔職業／場所／物件〕の〔名詞〕／2–4 字的意象／〔名字〕＋〔關係〕
- **經典作：** 薬屋のひとりごと・本好きの下剋上・魔法科高校の劣等生・長風渡・墨雨雲間・폭군의 셰프・재벌집 막내아들
- **為什麼有效：** 好做品牌、可以直接上海報、不怕被看輕；作品靠角色與口碑取勝時，它撐得起整部作品（薬屋のひとりごと 只有七個字，累計突破 4,500 萬部）。
- **最適合：** 動畫／電視／電影跨媒體、獎項、偏文學、懸疑或宮廷作品；雙名制裡的短名
- **風險 → 對策：** 平台列表上點擊率較低，容易流於抽象（F7）→ 名字裡要保留錨點名詞（薬屋、劣等生、셰프）。

### A9 主副標型
- **骨架：** 〔品牌名〕 ～〔一句話簡介〕～
- **經典作：** 無職転生 ～異世界行ったら本気だす～・本好きの下剋上 ～司書になるためには手段を選んでいられません～
- **為什麼有效：** 品牌和簡介一次給；改編成動畫、電視或周邊時可以拿掉副標。
- **最適合：** 打算跨媒體的網路連載；需要略稱的長書名
- **風險 → 對策：** 副標膨脹成 F6 → 副標最多一個子句，主標自己也要能通過閘門。

### A10 平台在地型（中／韓）
- **骨架（簡中）：** 〔類型前綴〕：〔一句話簡介〕／開局〜／我在〜當・學〜／重生後，〜／穿成〜的〜／〜後，〜／〜駕到／〜馬甲掉了
- **骨架（繁中）：** 〜的我，〜／明明是〜，卻〜／〜時〜，長大後〜／關於我〜這件事／〔鋪陳〕，〔回報〕
- **骨架（韓）：** ~로 살아남기／~에 빙의했다／~가 되었다／회귀한 ~／나 혼자만 ~
- **經典作：** 我在精神病院學斬神・十八歲太奶奶駕到，重整家族榮耀・三歲時被父母遺棄在副本，長大後成為副本主人並殺死進來的獵人們・연산군의 셰프로 살아남기
- **為什麼有效：** 符合平台本身的閱讀節奏與搜尋習慣；微短劇的雙子句結構＝鋪陳＋回報。
- **最適合：** 番茄／起點／飛盧／晉江連載、微短劇、KakaoPage／Naver Series
- **風險 → 對策：** 監管紅線（F10）與同質化（F5）→ 先查市場紅線清單；錨點名詞要不尋常。

## 二、類型 → 句型適配表

| 類型 | 首選 | 也很強 | 避免 |
|---|---|---|---|
| 異世界・轉生 | A1 | A2, A9, A6 | — |
| 追放・復仇・打臉 | A2 | A6, A10 | A3 |
| 戀愛喜劇・校園 | A3, A4 | A5, A7 | A6 |
| 惡役千金・女性向奇幻 | A1, A2 | A8, A10 | — |
| 古裝・宮鬥 | A8 | A2, A10 | A6 |
| 懸疑・推理 | A8, A7 | A6（當作規則用）, A5 | A1／A2（若會暴露機制） |
| 療癒・都會奇幻・靈異日常 | A4, A8 | A7, A3, A5, A6（當作代價或規則） | A2（素材裡沒有不平時） |
| 職人・美食・店舖日常 | A4, A8 | A2, A7 | — |
| 遊戲・獵人 | A6 | A1, A2 | — |
| 都市逆襲・身分反轉 | A10, A2 | A5, A7 | 不要拿 A8 當平台標題（只當跨媒體名） |
| 恐怖・規則怪談 | A6 | A8, A5 | A3 |

- 這張表是排序，不是禁令。「避免」的意思是：要用的話，必須在「風險與對策」寫出理由。
- 微短劇、動畫、電視是媒介，不是類型：先依類型選句型，再套用媒介規則（market-playbook §2）。混合類型就把對應的列合併參考。

## 三、整組提案的組合規則

1. 每個提案一種句型，不重複。
2. 依適用的長度區間（market-playbook §1–2）分散長度：至少一個長區間書名（負責曝光）、至少一個短區間書名（負責品牌），而且任何一個區間都不得超過整組的一半。
3. 只要有跨媒體的可能（動畫／電視／電影／短劇 IP），就放一個 A8 或 A7，同時兼作雙名。
4. 陳腔濫調模板（〜件／這件事）最多只能有一個提案使用。
5. 每個書名用它自己最強的錨點；整組至少用兩個不同的錨點，讓使用者是在不同切角之間選，而不是在不同措辭之間選（title-anatomy T1）。
6. 每個提案回答一個不同的「為什麼要點進來」：落差（A1、A7）、不平（A2）、角色（A3、A4）、態度（A5）、規則或代價（A6）、格調（A8）、一次看到全貌（A9）、平台原生的鉤子（A10，依它的子句實際承載什麼來歸類）。共用同一種「為什麼」的句型可以同時出現，但錨點必須不同。
7. A3 與 A5 的判別：否認關於自己或作品的事實＝A3；對某個人（客人、讀者、世界）嗆聲＝A5。
