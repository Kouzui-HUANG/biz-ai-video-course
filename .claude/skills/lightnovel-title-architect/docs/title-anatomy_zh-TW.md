## 一、六個欄位（＋略稱）

輕小說式書名最多由六個欄位組成，成功的書名通常只填 **2–4 個**。只填 ① 等於只堆類型詞（F1）；六個全填就是把簡介倒進書名（F6）。只計算書名裡明確出現的詞，隱含的類型不算填了 ①。一個詞可以同時填兩個欄位，標註時兩個編號都寫（②③無職、②③超商大夜店員）。

| 欄位 | 功能 | 典型詞 |
|---|---|---|
| ① 類型鑰匙 | 讓讀者大約一秒內判斷類型 | 転生・追放・悪役令嬢・婚約破棄／重生・穿成・開局／회귀・빙의・환생 |
| ② 身分／處境 | 主角是誰、卡在哪裡 | 無職・劣等生・被退婚的聖女・接手攤位的大學生 |
| ③ 錨點名詞 | 只屬於這部作品、畫得出來的具體名詞，作品的「臉」 | スライム・無限ガチャ・薬屋・精神病院・太奶奶 |
| ④ 機制／規則 | 能力、規則或限制 | 防御力に極振り・ロシア語でデレる・Re:（暗示重來） |
| ⑤ 承諾 | 讀者會反覆得到的那一種爽 | ざまぁ・スローライフ・本気だす・下剋上・溺愛・打臉 |
| ⑥ 聲口 | 句尾、人稱、標點，等於正文語氣的免費試讀 | 〜件・〜わけがない・〜ですが、なにか?・。・！ |
| ⑦ 略稱（書名之外） | 2–4 個單位的暱稱或 hashtag | 転スラ・俺妹・나혼렙・斬神 |

## 二、經典書名的欄位拆解

| 書名 | 填了哪些欄位 | 略稱 |
|---|---|---|
| 転生したらスライムだった件 | ①転生 ＋ ③スライム ＋ ⑥だった件 | 転スラ |
| 無職転生 ～異世界行ったら本気だす～ | ②無職 ＋ ①転生 ＋ ⑤本気だす | 無職転生 |
| 痛いのは嫌なので防御力に極振りしたいと思います。 | ②痛いのは嫌 ＋ ④極振り ＋ ⑥と思います。 | 防振り |
| 時々ボソッとロシア語でデレる隣のアーリャさん | ④ロシア語でデレる ＋ ②隣の ＋ ③アーリャさん | ロシデレ |
| 俺の妹がこんなに可愛いわけがない | ②俺の妹 ＋ ⑤可愛い ＋ ⑥わけがない | 俺妹 |
| Re:ゼロから始める異世界生活 | ①異世界 ＋ ④Re:（暗示重來，藏住死亡回歸） | リゼロ |
| 薬屋のひとりごと | ③薬屋 ＋ ⑥ひとりごと | 薬屋 |
| 我在精神病院學斬神 | ②我在 ＋ ③精神病院 ＋ ④學斬神 | 斬神 |
| 나 혼자만 레벨업 | ②나 혼자만 ＋ ④레벨업 | 나혼렙 |

## 三、語意技巧 T1–T6

**T1 錨點。** 錨點是具體的名詞或名詞片語，地點和時間也算（大夜班、凌晨三點）。用三項測試評分：**U** 是否只屬於這部作品（替換測試）、**D** 能否畫成縮圖、**T** 是否帶有張力（在這個類型裡出乎意料）。至少找三個候選，每個書名用它最強的那一個；整組提案至少要用到兩個不同的錨點，而次要錨點仍須通過 U 與 D。熟語改造（T6）的錨點可以藏在被換掉的那個字裡（炸 → 雞排）。スライム 勝過 魔物；精神病院 勝過 奇怪的地方；雞排 勝過 食物。

**T2 落差配對。** 把素材中語意距離最遠的兩個元素接在一起。

| 落差軸 | 例子 |
|---|---|
| 低身分 × 高風險 | 無職×転生・劣等生×魔法科・司書×下剋上 |
| 日常 × 史詩 | 精神病院×斬神・薬屋×後宮之謎 |
| 年齡／角色反轉 | 十八歲×太奶奶・魔王×打工（はたらく魔王さま!） |
| 類型融合 | 地下城×邂逅（ダンまち） |
| 祕密 × 公開 | 用俄語撒嬌：只有主角聽得懂 |

**T3 問題先行。** 書名裡要有缺陷、代價、詛咒、限制或反諷。純工具或純外掛型的錨點，會在問題出現之前就先講出答案。公式：*能力＋限制*（防御力に極振り），或 *身分＋缺陷*（劣等生、悪役令嬢）。反例：異世界はスマートフォンとともに。（F2）。

**T4 藏住機制。** 說出前提與爽點類型，絕不說反轉、結局或隱藏的核心機制。改用暗示：符號（Re:）、委婉語（魔法少女育成計画 用「育成計画」包住死亡遊戲）、問句（〜だろうか），或只講規則不講後果。**前提與底牌的分界：** 第一集或第一章（大約故事的前十分之一）就揭露的內容屬於前提，可以放進書名；只有它後來造成的後果（也就是它引出的反轉）才列入禁說清單。例如第一集就交代「用記憶換願望」是前提，可以入題；這個代價最後牽出的那個被遺忘的人，才是底牌。

**T5 承諾＝核心循環。** 承諾詞必須說出一集又一集反覆發生的事，並能用素材原句證明。

| 爽點 | 日 | 中 | 韓 |
|---|---|---|---|
| 復仇／打臉 | ざまぁ・見返す | 打臉・逆襲・復仇 | 복수・참교육・사이다 |
| 慢活 | スローライフ・のんびり | 慢活・種田 | 힐링 |
| 碾壓 | 無双・最強・チート | 無敵・外掛・開掛 | 먼치킨 |
| 崛起 | 成り上がり・下剋上 | 翻身・逆襲 | 성장 |
| 避開毀滅結局 | 破滅フラグ回避 | 改命・避開 BE | 생존 |
| 寵溺戀愛 | 溺愛 | 寵・偏愛 | 집착・후회 |
| 療癒／暖心 | ほっこり・癒やし | 療癒・暖心 | 힐링・감동 |
| 苦甜／催淚 | 泣ける・切ない | 催淚・虐心 | 눈물・신파 |

**單元訪客循環**（店舖、旅店、診所、大夜班）：承諾的就是那個儀式本身，把場所連同它的時段或規則一起寫出來（深夜食堂、薬屋のひとりごと、大夜班）。

**T6 熟語改造。** 拿一個觀眾倒背如流的詞組，換掉其中一個元素：전지적 작가 시점 → 전지적 독자 시점；（示意）酒後吐真言 → 炸後吐真言。只有原詞在目標語言裡夠普及才有效；改造過的熟語絕不直譯，每個市場要重新造一個。

## 四、聲口：句尾、標點、人稱

**起源。** 這種書名模仿的是論壇討論串標題（2ch VIP 板的スレタイ）：用第一人稱、一本正經地回報一件事，讓人想點進去。「〜な件」大約在 2011 年進入商業輕小說書名。

| 動作 | 日 | 繁中 | 簡中 | 韓 |
|---|---|---|---|---|
| 回報 | 〜だった件 | 關於我〜這件事 | 关于我〜这件事 | ~건에 대하여 |
| 否認 | 〜わけがない | 〜哪有這麼〜 | 〜哪有这么〜 | ~리가 없어 |
| 提問 | 〜だろうか | 〜是否搞錯了什麼 | 〜是否搞错了什么 | ~걸까 |
| 決定 | 〜ことにしました | 於是我決定〜 | 于是我决定〜 | ~하기로 했다 |
| 嗆聲 | 〜ですが、なにか? | 〜又怎樣？ | 〜又怎样？ | ~인데요, 뭐? |

**標點就是態度。**

| 標點 | 效果 | 經典作 |
|---|---|---|
| 。 | 冷淡的定論、認命 | やはり俺の青春ラブコメはまちがっている。 |
| ！ | 喜劇能量、驚呼 | この素晴らしい世界に祝福を!・負けヒロインが多すぎる! |
| ？ | 邀請讀者回答 | ダンまち・蜘蛛ですが、なにか? |
| … | 無奈、拖長的嘆氣 | 〜悪役令嬢に転生してしまった… |
| 〜と思います。 | 用禮貌語氣說荒謬的事 | 防振り |
| ～副標～ | 切開品牌和簡介 | 無職転生 ～異世界行ったら本気だす～ |

**人稱與敬稱。** 俺（男性向、衝）・僕（溫和）・私（女性向或正式）・本王／本宮（用位階當聲口）。〜さん・〜くん・〜様 決定敘事者和對象之間的距離。

**陳腔濫調的用量。** 「〜件」其實比它的名聲少得多：到 2019 年初，書名用「〜な件」的已出版輕小說只有 20 部，所以它現在讀起來像模板符號。「〜件／這件事／這檔事／건에 대하여」一組提案最多用一次，而且只在正文真的是一本正經回報口吻時才用。
