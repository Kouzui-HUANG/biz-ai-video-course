# 人像光影知識庫（繁中閱讀版）

> 本檔為 `references/lighting-knowledge-base.md` 的人類閱讀版，不會被 AI 載入執行。英文詞庫（§10）刻意保留英文原文，因為那是要直接貼進提示詞用的。

## 一、三大設計軸

三者**互相獨立**，不是同一條刻度。多數需求是混合的——動手設計前先決定比例（例如 唯美 70%／氣氛 30%）。

| | 唯美 Ethereal | 專業 Clean/Commercial | 氣氛 Cinematic/Moody |
|---|---|---|---|
| 主光方向 | 逆光／側逆光 | 前側 45° | 強方向性、離軸 |
| 光質 | 極柔、超大光源、羽化 | 柔但受控（加格柵） | 較硬、有造型、有出處 |
| 光比 | 1:1.5–1:2 | 1:3–1:4 | 1:8–1:16 |
| 黑位 | 上浮、霧面過渡 | 真黑、乾淨 | 壓死、深沉 |
| 標誌 | 髮絲光暈、bloom、薄霧、光斑 | 輪廓分離、乾淨眼神光 | 體積光束、gobo 造型陰影 |
| 色彩 | 暖、低飽和粉彩 | 中性、準確 | 冷暖分離或單色洗光 |
| 風險 | 糊成一團、沒有結構 | 無菌、沒有情緒 | 髒濁、臉看不清 |

**各自的解藥**：唯美 → 保留一道銳利的邊（下顎的輪廓光，或一隻合焦的眼睛）。專業 → 讓其中一道陰影有形狀。氣氛 → 至少保證一個眼神光與一隻讀得到的眼睛。

## 二、核心變數

**光質＝光源的視角大小。** 柔不柔只取決於從被攝者位置看過去光源有多大。同一顆柔光箱：**拉近** → 更柔，且衰減更快（背景沉下去）；**拉遠** → 更硬，但覆蓋更均勻。這一個控制桿就能從一盞燈做出兩種完全不同的樣子。

**用反平方定律控背景。** 想壓暗背景又不動它：把主燈推近、功率調小。想讓人與背景一起亮：把主燈拉遠。

**光比**（主光 vs 補光，以級數計）：1:1–1:2（0–1 級）＝平、通透、廣告感；1:3–1:4（1.5–2 級）＝經典人像立體感；1:8 以上（3 級＋）＝低調、戲劇、明暗對照。

**減光 Negative fill** — 業餘與專業的分水嶺。暗面擺黑旗，減去環境反射，明暗轉折線才會出現。多數人只想著「加光」；專業的塑形來自「減光」。

**羽化打光 Feathering** — 用柔光罩的**邊緣**掃過臉，而非拿正中心對著打。衰減梯度被拉長 → 絲綢般的膚質過渡。這就是「唯美」質感的技術來源。

## 三、臉部布光法

| 布光法 | 燈位 | 特徵 | 適合 |
|---|---|---|---|
| **蝴蝶光** Butterfly | 高、正前方 | 鼻下小蝴蝶形陰影 | 華麗感、美妝、顴骨 |
| **林布蘭光** Rembrandt | 約 45° 側上方 | 暗面顴骨的三角光斑——不長於鼻、不寬於眼 | 油畫感、厚重、古典 |
| **環形光** Loop | 比林布蘭再正一點 | 短鼻影，不接到臉頰陰影 | **最泛用，幾乎不挑臉** |
| **分割光** Split | 90° 正側 | 半明半暗 | 張力、神秘、noir |
| **蚌殼光** Clamshell | 上主燈＋下反光板 | 極勻膚質、上下雙眼神光 | 美妝，最保險的「乾淨美」 |
| **短邊光** Short | 受光面「背對」鏡頭 | 顯瘦、有情緒 | **人像預設首選** |
| **寬光** Broad | 受光面朝向鏡頭 | 臉變寬 | 除非刻意要開朗感，否則避開 |

燈高規則：略**高於**眼＝有神且顯瘦；**齊**眼＝親近中性；**低於**眼＝底光，詭異／陰森。

## 四、控光器材性格

柔光箱＝均勻可預測、方形眼神光｜雷達罩＝半柔但高光有「芯」｜拋物線傘＝聚焦柔光，高對比卻溫柔｜透射傘＝四處溢光、寬容、生活感｜菲涅爾＝硬光、陰影邊緣銳利、老好萊塢｜束光筒／光學聚光＝單一小塊硬光斑｜環形燈＝無影、環形眼神光｜跳燈＝巨大間接光源、自然室內感。

反光板顏色：**白**＝自然補光｜**銀**＝銳利高光｜**金**＝暖膚色｜**黑**＝減光（做減法）。

**高光滾落 Specular roll-off** — 大光源讓高光成為一長段漸層，而非一塊白斑。這段漸層就是「高級感」的來源。

## 五、自然光情境

北向窗＋白紗＝天然柔光箱，全天穩定，越近越柔且衰減越快｜陰天＝天空大小的柔光箱，需靠門洞或牆給方向，否則太平｜黃金時刻逆光＝低角暖陽在後，髮絲光＋霧氣，下巴用金反光板｜藍調時刻＋一盞暖光源＝零色片自動冷暖分離｜開放陰影＝柔和中性，但小心植物反射的綠色偏色｜斑駁光＝浪漫，但不能亂灑在眼睛上｜逆光下的霧氣／海霧／塵埃＝讓光本身被看見，取得氛圍最便宜的路。

## 六、可直接引用的風格流派

老好萊塢華麗風（Hurrell）：硬菲涅爾＋蝴蝶光＋強髮絲光＋深黑背景，眼睛像會發光｜黑色電影 Film Noir：分割光、百葉窗 gobo、煙霧、1:16｜荷蘭黃金時代（Vermeer／Rembrandt）：單一左窗、暗背景、臉上急速衰減｜卡拉瓦喬明暗對照法 Tenebrism：一道陡峭頂光，其餘全滅｜日系高調：牆面跳燈、微過曝、低對比、通透｜Peter Lindbergh：純自然光、黑白、粗顆粒、不美化｜Paolo Roversi：長曝＋手電筒描光，夢境般的柔｜Gregory Crewdson：整組劇組燈光打在一張靜照上，超現實郊區｜韓系棚拍：近乎無影、高調、極勻｜時尚編輯風：雷達罩／拋物線主光、偏硬、彩色背景片、強分離。

## 七、氛圍工具

物理效果永遠勝過後製，要明確寫出來。薄霧／海霧 → 讓光束可見（體積光、丁達爾光束）｜**實用光源**（霓虹、檯燈、燭火、螢幕、街燈）→ 讓光在畫面內有可見的出處；「有出處的光」是氣氛的核心｜**Gobo／造型片** → 百葉窗陰影、樹影、窗櫺影｜**前景遮擋** → 穿過樹葉、布料、玻璃拍｜**逆光中的顆粒** → 塵埃、海浪飛沫、花瓣、雪｜**鏡頭伎倆** → 變形寬銀幕橫向光斑、稜鏡光斑、Helios 旋轉焦外、無鍍膜鏡頭的紗幕眩光、高光暈開｜**潮濕表面** → 雨、水氣、濕沙，把每個光源都乘以數倍的反光點。

## 八、色溫敘事

暖＝回憶、安全、黃昏、親密。冷＝疏離、清晨、都市孤獨。
CTO 主光＋CTB 環境光 → 經典電影感冷暖分離｜洋紅＋綠 → 不安、賽博、臨床感的恐懼｜單色洗光 → 強烈作者印記｜**色片紀律**：打背景的色片**必須**加蜂巢格柵，否則顏色會污染皮膚、把膚色弄濁。

## 九、光角與膚質

正面光壓抑毛孔 → 美妝、少女感、精緻。掠射側光放大紋理 → 年齡、手、布料、歷經風霜的角色感。把主燈從 0° 移到 80°，人物的**故事**就從「無瑕」變成「有經歷」。這要刻意選擇，並在提示詞裡寫明。

## 十一、避雷清單

| 症狀 | 成因 | 提示詞上的解法 |
|---|---|---|
| 熊貓眼、眼窩死黑 | 主燈太高 | 把主燈降向眼高；要求可見的眼神光 |
| 兩道陰影／兩組眼神光 | 補光太強或有第二主光 | 指明「唯一」主光與從屬補光 |
| 膚色一半黃一半綠 | 混合色溫 | 宣告單一主導色溫；色片加格柵 |
| 背景比臉亮 | 沒控衰減 | 明確下令壓暗背景 |
| 臉扁如煎餅 | 沒有光比、沒有減光 | 寫出光比並加入減光 |
| 暗面髒濁不可讀 | 黑位壓死卻沒有輪廓光 | 加輪廓光／邊光重畫剪影邊緣 |
