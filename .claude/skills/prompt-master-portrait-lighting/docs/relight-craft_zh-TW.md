# 重打光工藝：怎麼寫這段圖片編輯提示詞（繁中閱讀版）

> 本檔為 `references/relight-craft.md` 的人類閱讀版，不會被 AI 載入執行。

針對「替一張既有人像照片重新打光」（而非從零生成）的專屬技術規則。

## 一、重打光可行性分級

**在承諾任何事之前，先讀懂原圖既有的光。** 圖像模型無法單純「加一道輪廓光」——它必須重新演算整張臉的明暗，而只要新設計與已烘進像素裡的陰影相牴觸，它要嘛無視指令、要嘛把臉融掉。先分級，這同時決定了第一階段該提什麼案、第二階段要帶什麼覆蓋語句。

| 原圖狀況 | 可達成範圍 | 提示詞必須怎麼處理 |
|---|---|---|
| **平光／柔光／陰天／環形燈** | 幾乎任何方向 | 最容易。直接完整描述新光即可。 |
| **柔性方向光（窗光）** | 同一側半球內都行；對側是硬仗 | 新主光留在原本那一側，或明確下令反轉。 |
| **硬方向光、陰影銳利** | 同方向加強可以；其他都需先拆除 | 必須開頭就明確移除：「左頰上原有的硬陰影完全消融，替換為……」。不寫這句，畫面會出現兩套打架的陰影系統。 |
| **強逆光／剪影** | 加更多逆光，或補正面光 | 暗部的臉部細節可能根本不存在，要事先警告使用者臉會被部分「重新發明」。 |
| **混合光／彩色光（霓虹、舞台）** | 要中和回來很難 | 明確宣告新的主導色溫，並下令中和舊的偏色。 |

**方向反轉**是破壞性最高的需求。必須外科手術式地寫清楚：「光線方向反轉——原本位於陰影中的右臉現在承接主光，原本受光的左臉落入柔和陰影；所有原始陰影形狀全部移除，並依新的光位重新推導。」

**要對使用者說。** 如果分級判定這個需求高風險，就在第一階段用一句話講出來，並提供一個低風險的替代方向——不要默默產出一段注定失敗的提示詞。

## 二、身分與神韻鎖定

重打光＝重新演算臉，而重新演算就會讓神韻漂移。每一段編譯出的提示詞都**必須**嵌入身分鎖定句，把五官標記寫成硬性約束而不是建議。

要點名原圖中實際可見的標記：**額頭高度・兩眼間距・眼型與眼皮類型・眉形與眉高・鼻長鼻寬鼻頭・嘴寬與唇比例・人中・顴骨位置・臉型・下顎與下巴・髮際線與髮型・任何痣、雀斑或疤痕**。

可重複使用的模板（依實際照片調整細節）：

> the subject's facial identity is preserved with absolute fidelity — the same forehead height, the same interocular eye spacing, the same eye shape and lid type, the same brow arch and height, the same nose length, width and tip, the same mouth width and lip proportion, the same cheekbone position, face shape, jawline and chin, the same hairline, hairstyle and individual markings; only the light falling across these unchanged features is redesigned, and no feature is slimmed, widened, enlarged, shortened, lifted or repositioned

**兩眼間距**與**額頭高度**是最常漂移的兩個標記——永遠要點名。

**姿勢、視線、表情、服裝同樣鎖定**，除非使用者要求更動。預設的編輯只有光（有指定時再加場景）。

## 三、光與場景一致性法則

當需求改變了環境（棚拍 → 沙灘、咖啡廳、夜間街道），第一號失敗就是：人物還穿著舊的棚燈光，被貼到新場景上。這種合成一眼就看得出是假的。

每一次場景更動都**必須**指定以下四項，且人物的光必須從**場景自身的光源推導**出來：

1. **方向** — 場景的光從哪裡來，臉上對應的主光位置在哪。
2. **色溫** — 場景的主導色溫，以及皮膚上相同的偏色。
3. **硬度** — 沙灘正午的太陽是硬的，海霧陰天是柔的。臉必須吻合。
4. **反射與環境光** — 點名環境反射回來什麼：沙與水會把暖光往下巴底下打；森林反射綠色；雪從下方補光；紅牆會把暗面染紅。

要寫成一句有因果的敘述，例如：「低斜的太陽位於她左肩後方，因此她的髮絲帶著暖色輪廓光，而明亮的沙地把柔和的金色反射光打回她臉上的暗面。」**因果關係**才是讓合成讀起來像同一張照片的關鍵。

另外要寫明人物的**比例、透視與地平線**與新環境一致，且可見範圍內的接地（腳、沙上的影子）在物理上正確。

## 四、景別紀律

先判斷原圖的景別（大頭肩、胸上、腰上、全身）。**只描述落在那個裁切之內的東西。** 提到框外的衣物、道具或身體部位，會逼模型為了「把它放進來」而拉遠鏡頭，毀掉構圖。

預設收尾指令：「keep the exact same framing, crop and shot distance; do not zoom out, widen, re-pose, or extend the composition.」

若需求真的需要更寬的視野（沙灘場景在緊裁的大頭照裡根本讀不出來），**不要默默拉寬**——在第一階段把它當成一個明確的選項提出來；確認後再直接下令重新取景，並指名新的景別。

## 五、乾淨膚質渲染區塊

只要畫面裡有人類皮膚就強制使用。正負兩半都要**融進散文**，絕不能在提示詞裡列成標題或項目符號。原文見 `references/relight-craft.md` §5。

- **正面半段**（併入主體描述）：膚色渲染得極為乾淨勻稱、額頰顎連續柔順的影調過渡、自然柔霧質感、毛孔只是柔性暗示而非誇張、完全沒有斑駁／色塊／泛紅／髒污／陰影汙濁，保有健康的活膚質感、但沒有塑膠般過度磨皮的空氣刷感。
- **負面半段**（併入結尾攝影句）：白平衡準確、皮膚沒有任何綠／灰／洋紅偏色、基準 ISO 拍攝、高訊噪比高位元深度渲染——絕無彩噪、色噪、亮度噪點、感光元件噪點、斑點或抖動、色階斷層、色調分離、壓縮瑕疵，臉上沒有濁髒的影調。

**刻意顆粒的例外**：某些光影設計本來就該有顆粒（Lindbergh 黑白、noir、推感夜拍）。當顆粒是需求的一部分時，保留顆粒、拿掉顆粒相關的負面詞，其餘照留，並明確寫出 `fine even silver-halide grain, never chroma noise or blotchy digital mottling`。

**刻意暗部的例外**：1:8 的明暗對照設計裡，暗面本來就**應該**沉入黑色。「無陰影汙濁」管的是**受光面**與過渡區，不能拿來把刻意的黑壓平。

## 六、禁用詞彙

以下絕不可寫——擴散模型會把它們讀成「可以把臉渲染得髒」的許可：
`unretouched texture`、`no skin smoothing`、`no retouching`、`raw skin texture`、`every pore visible`、`detailed pores`、`skin imperfections retained`、`natural skin texture fully retained`。

要表達「不要塑膠感」，安全的講法是：毛孔只做**柔性暗示** ＋ 明確禁止過度磨皮。

同時避開毫無光學指令的空泛詞：`beautiful lighting`、`professional lighting`、`good light`、單獨的 `dramatic lighting`、單獨的 `cinematic`。每一句光線主張都必須指名方向、光質、光比或具名布光法。

## 七、黃金解構順序

編譯成**單一連續英文段落**，不得有標題，並依此權重順序排列——越前面的區塊得到模型越多注意力：

1. **重打光指令** — 新的光影設計，放最前面且寫完整：主光方向與高度、光源大小與光質、布光法名稱、光比、減光、輪廓光／髮絲光、背景衰減。含任何對原圖陰影系統的明確拆除令。
2. **場景與環境**（僅在需求更動場景時）— 新場所、它自己的光源、時間、天氣、氛圍，以及它反射回主體身上的光。必須與區塊 1 因果一致。
3. **身分與保留元素** — 身分鎖定句，加上姿勢、視線、表情、髮型、服裝，以及任何必須存活下來的背景元素。
4. **膚質渲染** — 乾淨膚質渲染區塊的正面半段。
5. **攝影、媒材與構圖鎖定** — 鏡頭與距離語言、繼承原圖媒材／色彩反應／調色的指令、構圖鎖定句，以及乾淨膚質渲染區塊的負面半段。

## 八、完整範例

**需求**：一張平光正面的胸上棚拍人像 →「唯美的沙灘攝影」。
**分級**：平光柔光源 → 低風險，新主光可自由擺放。
**設計**：唯美 80%／氣氛 20% — 黃金時刻背主光、1:2 光比、沙地反射當補光、海霧。

完整的英文提示詞範例見 `references/relight-craft.md` §8。其結構示範了：區塊 1 同時寫明方向、高度、光質、光比、衰減**並且**殺掉舊陰影；區塊 2 提供的沙地反射，正是**造成**區塊 1 補光的原因；區塊 3 鎖住身分與姿勢；區塊 4–5 以膚質與景別紀律收尾。
