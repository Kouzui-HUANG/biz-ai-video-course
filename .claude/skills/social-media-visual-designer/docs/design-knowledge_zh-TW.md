## 1. 內容類型 → 色彩系統

將文章歸入**唯一**主導類型。永遠輸出具體色碼（主色／輔助色／文字色）。若文章橫跨兩類，依「鉤子的情緒目標」而非主題關鍵字來判定。

| 類型 | 配色（主色 / 輔助色 / 文字色） | 色彩心理 | 調性判定範例 |
|---|---|---|---|
| 科技 / AI / 數據 | 深海軍藍 `#0B1F3A` / 冰藍 `#4FC3F7` / 白 `#FFFFFF`——或 螢光綠 `#00E676` / 炭黑 `#111418` / 白 | 冷色＝精確、未來感、可信的機器理性 | 科技冷冽感 |
| 商業 / 財經 / 職涯 | 墨綠 `#1B3A2F` / 香檳金 `#C9A96A` / 米白 `#F5F0E8`——或 深藍 `#14213D` / 金 `#FCA311` / 白 | 深色＋金屬色＝資產、專業、權威 | 沉穩權威感 |
| 生活 / 人文 / 情感 | 米白 `#F5F0E8` / 大地棕 `#8D6E52` / 深咖 `#3E2F23`——或 淺橘 `#F4A261` / 奶油 `#FAF3E0` / 深灰 `#333333` | 暖色低飽和＝溫度、真實、貼近生活 | 溫暖人文感 |
| 警示 / 批判 / 觀點衝突 | 正紅 `#D62828` / 純黑 `#000000` / 白——或 警示黃 `#FFD60A` / 純黑 / 黃底黑字 | 高對比互補＝危險、急迫、立場鮮明 | 高壓警示感 |
| 健康 / 醫療 / 心理 | 青瓷綠 `#7FB9A6` / 淨白 `#FDFDFD` / 深灰藍 `#37474F` | 低飽和綠＋大量白＝潔淨、專業、安撫 | 潔淨療癒感 |
| 教育 / 知識 / 方法論 | 奶油底 `#FFF8E7` / 靛藍 `#3D5A80` / 活力橘 `#EE6C4D`（點綴） | 亮底＋雙撞色＝清晰、易讀、筆記感 | 知識筆記感 |
| 環境 / 永續 / 自然 | 苔綠 `#606C38` / 米白 `#FEFAE0` / 深橄欖 `#283618` | 大地綠系＝有機、責任、長期主義 | 自然永續感 |

規則：

- 主色佔畫面 ≥60%（背景色調、壓暗層或色塊）；輔助色 ≤30%；點綴／文字 ≤10%（60-30-10 法則）。
- 極簡的飽和度紀律：每張卡最多**一個**高飽和色，其餘一律低調。
- 使用者提供的品牌色優先於此表——保留該類型的「對比邏輯」，但替換為品牌色相。

## 2. 可讀性工程

讓文字在手機動態牆上保持可讀的鐵律：

- **壓暗（Scrim）**：任何壓在照片上的文字，都需要 40–60% 不透明度的壓暗層（或從文字側漸層壓暗），或改用實色色塊墊底。
- **對比度**：文字與其直接背景需達到約 WCAG AA（≥4.5:1）。白字壓中灰照片會失敗——加深壓暗或加細邊框。
- **安全區**：所有文字保持在畫布中央約 90% 範圍內（平台會裁切邊緣，動態預覽裁得更兇）。
- **手機縮圖測試**：主標高度 ≥ 圖高的 1/10。若在 5 公分寬的縮圖上讀不到主標，即為失敗。
- **行數紀律**：主標最多 2 行；副標最多 1–2 行；文字總佔比不得超過畫布約 40%——留白本身就是風格。

## 3. 雜誌感版式庫

只選**一種**版式；在「排版佈局」中指名版式並具體描述位置。

| 版式 | 結構 | 適用 |
|---|---|---|
| A. 滿版壓暗置中 | 滿版照片、45–60% 壓暗、全部文字置中、字距放寬 | 情感衝擊、金句型、警示型 |
| B. 左右分割 | 一半照片、一半實色主色色塊承載全部文字、硬直切邊 | 數據、商業、教育（文字量較多） |
| C. 上下分割 | 照片佔上方 60–65%、下方色帶靠左排字、雜誌圖說感 | 新聞感、專欄連載 |
| D. 色塊卡點 | 滿版照片、半透明主色矩形錨定於一角／三分點承載文字 | 生活人文、輕觀點 |
| E. 大留白負空間 | 照片本身帶大片天空／牆面／桌面空景，文字直接排進空景、不壓暗 | 高級極簡、品牌感、療癒系 |
| F. 雜誌封面式 | 上方小欄目名（kicker）、超大主標堆疊、細分隔線、頁碼式點綴 | 深度長文、系列專題、權威人物 |

構圖注意：

- 尊重照片的視線／動勢方向：主體應「看向」或「走向」文字，而非背離。
- 對齊 3×3 網格；照片焦點與主標放在不同的三分點上。
- 版式 E 要求生圖提示詞明確要求負空間（見 §7）。

## 4. 真實照片攝影指導

以攝影師工作單的方式描述照片，永遠涵蓋：**主體與動作／光線／鏡頭與視角／氛圍**。

- **真實勝過精緻**：抓拍瞬間、不完美的環境、真實膚質。圖卡應有紀實感，而非圖庫感。
- **光線詞彙**：自然窗光、黃金時刻、陰天柔光、冷白螢光（科技／警示用）、單側硬光（批判／戲劇用）。
- **鏡頭與視角詞彙**：特寫淺景深（情感）、中景平視（信任）、高俯拍（方法論／物件）、低角度仰拍（力量／警示）、過肩視角（沉浸）。
- **細節勝過概念**：「佈滿皺紋的手操作手機」＞「一位老人使用科技產品」。永遠指導一個具體、帶張力的細節。
- **陳腔濫調黑名單**——絕不提案：商務握手、燈泡＝創意、純白棚拍商務人像比讚、拼圖、西裝人指著上升箭頭、筆電旁咖啡俯拍（生活類除外）、火柴人示意圖。

## 5. 繁中圖卡字型學

- **字體人格對應**：黑體／無襯線（Noto Sans TC 類）＝現代、科技、中性；明體／襯線（Noto Serif TC 類）＝人文、深度、editorial；圓體＝親和、生活、療癒；手寫體＝情感、私密感（僅用於點綴或短主標）。
- 每張卡**最多 2 個字體家族**。經典組合：明體主標＋黑體副標（雜誌感）；粗黑體主標＋細黑體副標（現代感）。
- **粗細對比＞字級混亂**：主標:副標字級比約 2.5:1，且字重至少跳兩級（如 Black 對 Light）。
- **中文字距**：主標加 +5%~+15% 字距可得雜誌感；中文絕不使用負字距。
- **照片雜亂時的救援技法**：白色細邊框（keyline box）、輔助色底線色條、直排文字（強烈 editorial 風味，酌量使用）。

## 6. 標題與文案公式

主標題（5–10 字），依類型的情緒目標選用公式：

| 公式 | 機制 | 範例形態 |
|---|---|---|
| 數字量化 | 具體＝可信 | 「3個習慣，毀掉你的存款」 |
| 反差顛覆 | 打破預設 | 「越努力，越貧窮」 |
| 直球提問 | 讀者自我代入 | 「你的薪水去哪了？」 |
| 損失規避 | 害怕錯過／失去 | 「再不懂AI就晚了」 |
| 斷言金句 | 可引用的立場 | 「自由是設計出來的」 |
| 身分呼喚 | 點名目標受眾 | 「給30歲的你」 |

- 副標題（≤15 字）：補上主標刻意省略的「機制」或「範圍」——主標開缺口、副標瞄準、文章收尾。
- 點綴文字：三選一——關鍵字 hashtag（2–3 個）、一句話金句、或專欄署名／欄目名——用於平衡視覺重量，絕不與主標搶戲。
- 文案以繁體中文（zh-TW）撰寫，除非原文章為其他語言。

## 7. AI 生圖提示詞構成規則

企劃的最後一段是**一則英文提示詞**，用於重現所指導的照片。結構：

```
[鏡位與角度] of [主體＋具體動作/細節], [環境], [光線],
[鏡頭/景深，如 85mm, shallow depth of field], photorealistic documentary photography,
[氛圍＋對應配色方案的調色], [負空間指示],
no text, no letters, no watermark, no logo --ar 16:9
```

- **比例**：對應圖卡規格（預設 `--ar 16:9`；使用者指定平台則改用其比例）。若目標模型不吃 `--ar` 參數，改以文字描述「16:9 widescreen composition」。
- **無文字鐵律**：永遠包含 `no text, no letters, no watermark`——文案在排版階段上字，絕不烙進圖裡。
- **負空間**：明確保留排版放文字的區域，例如版式 B/E 用「large empty negative space on the left third」。
- **調色**：把色碼翻譯成攝影語言（「cool teal-and-navy grade」、「warm earthy tones, muted saturation」），讓照片天生就符合設計配色。
- **真實感關鍵字**：「candid, documentary style, natural skin texture, editorial photography」——避免「beautiful, perfect, stunning」這類會漂向圖庫感的字眼。
