## 1. 動筆前鎖死三件事

| 項目 | 檢驗標準 |
|---|---|
| **Logline** | 「當〔事件〕發生，〔有缺陷的主角〕必須〔具體目標〕，否則〔明確代價〕。」一句講不清楚，後面全部會歪。 |
| **Want vs Need** | Want＝外在目標（推動情節）；Need＝內在缺口（推動弧線）。兩者相同＝沒深度；毫無關聯＝故事會散。正解是**互相拉扯**。 |
| **主題論證** | 不是「談愛情」，而是「愛必須以放棄控制為代價」。這是砍場次的刀：不服務論證的戲一律砍。 |

三者鎖不死就不要進 Draft α。

## 2. 場次層級結構（真正的分水嶺）

- **每場都要有 目標 → 阻礙 → 結果**，且結果必須改變處境。刪掉不影響後續的場＝該刪。
- **價值轉向（value turn）**：場次開始與結束的情緒／權力狀態必須翻轉（＋轉－ 或 －轉＋）。全場平的戲是死戲。
- **晚進早出（late in, early out）**：切進衝突已經開始的那一刻，在答案揭曉前一秒切走。節奏是這樣省出來的。
- **因果串接**：場與場之間用「因此／但是」連接，不是「然後」。連續三個「然後」＝流水帳，回去重排。
- **場次功能唯一性**：每場只承擔一個主要功能。一場戲想同時交代三件事，三件都會模糊。

## 3. 幕結構與轉折點的功能

| 位置 | 功能 |
|---|---|
| 開場 | 建立常態＋提出戲劇性問題。第一個畫面要與最後一個畫面對話。 |
| 觸發事件 | 打破常態，主角被迫行動（不是自願，是**被迫**）。 |
| 第一轉折 | 主角做出無法回頭的選擇，進入陌生規則的世界。 |
| 中點 | 假的成功或假的失敗，並讓主角看見真正的賭注。 |
| 低谷 | 舊方法徹底失效，Want 與 Need 正面對撞。 |
| 第三幕 | 主角用新的自己解決問題（或拒絕改變而付出代價）。 |
| 結尾 | 回答開場提出的問題，但答案不能是主角用嘴講的。 |

短片可壓縮為「常態 → 打斷 → 抵抗 → 代價 → 落點」五拍，但**每一拍的功能不能省**。

## 4. 角色：功能先於個性

- 角色不靠設定表立起來，靠**壓力下的選擇**。給他一個沒有好選項的處境，他選什麼，他就是什麼。
- **反派要有自己的正當性**。反派只是壞，主角的勝利就不值錢。寫反派時要能替他寫出一段自己相信的辯詞。
- **配角必須有功能**，四種常見型：質疑者、鏡像、催化劑、代價體現者。沒功能的配角合併或刪除。
- **弧線 ＝ 缺陷被系統性攻擊**：中點嚐到假的成功 → 低谷讓舊方法徹底失效 → 第三幕才有資格改變。
- **主角必須主動**。被劇情推著走的主角，是第一稿最常見的病。每一幕至少要有一次「他自己決定去做某件事」。

## 5. 視覺化：把內在寫成可拍的東西

- **外化／客觀對應物**：「她很焦慮」不能拍；「她第四次把已經對齊的餐具再對齊一次」可以拍。
- **具體化**：攝影機拍不到「一個舊物件」。要選**那一個**特定的道具——鋼筆和生鏽鑰匙，是兩種不同的關係。
- **資訊經濟學**：觀眾知道得越少、推得越多，參與感越強。刻意決定「誰在什麼時候知道什麼」。
- **鋪陳與回收**：第三幕用到的東西，第一幕必須出現過——但要「順帶」出現，不能刻意展示。
- **動作行只寫拍得到的**：不寫「他想起童年」，寫「他的手停在門把上」。

## 6. 可拍性與預算意識

- 標準格式下**一頁約一分鐘**，這是製片估工期與預算的基準。
- 動作段落一段 **3–4 行以內**；長段落是「沒拍過片」的標記。
- 每一項都是錢：夜戲、雨戲、群眾、動物、小孩、車拍、特殊場景、爆破。寫的當下就要知道自己花了多少。
- 不寫鏡頭指示（景別／運鏡屬於導演），除非那個鏡頭本身就是敘事手段。
- 遵守立項時宣告的場景數／角色數上限；超出就重新設計，不要指望製作端吸收。

## 7. 商業短片／短影音／AI 生成影片的額外規則

- **前 3 秒定生死**：最強的畫面或最反直覺的一句話放最前，不要鋪陳。
- **一支片一個訊息**：講三件事等於一件都沒講。
- **CTA 不能突兀**：行動呼籲要由劇情自然導出，不是結尾貼上去。
- **AI 生成影片還要顧連戲**：角色外觀、服裝、光線、色調需逐鏡鎖定（character lock）；劇本要以「單鏡可執行的具體視覺描述」書寫，抽象情緒詞 AI 讀不懂。
- 短影音的「場次」實際上是**鏡頭群**，寫作時以 3–8 秒為單位切分。

## 8. 場次表建構法

在 Draft α 之前，先產出場次表（beat sheet），每場一行：

```
S03 ｜ 內・老家廚房・夜 ｜ 阿明想拿回母親的存摺，被姊姊擋下 ｜ 結果：拿到了，但姊姊不再跟他說話（＋轉－）
```

四個欄位：**編號｜場景（內外・地點・時間）｜目標與阻礙｜結果與價值轉向**。

檢查：
- 場次數符合長度換算表（見 `format-and-output.md`）。
- 逐場問：刪掉會不會影響後面？
- 逐場標 ＋／－：不能連續三場同向。
- 場與場能不能用「因此／但是」串起來？
