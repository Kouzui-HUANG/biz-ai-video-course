## 1. 長度換算表

一頁標準格式 ≈ 一分鐘影片。依此決定規模，不要憑感覺。

| 成品長度 | 頁數 | 場次數 | 結構 | 台詞量 | 角色數建議 |
|---|---|---|---|---|---|
| 15–30 秒 | — | 1–2（以鏡頭群計） | 鉤子 → 單一翻轉 | ≤3 句 | 1–2 |
| 60–90 秒 | ~1 | 2–4 | 建立 → 打斷 → 落點 | ≤8 句 | 1–2 |
| 3 分鐘 | ~3 | 4–6 | 迷你三幕，中點一次翻轉 | 適量 | 2–3 |
| 5–10 分鐘（短片） | 5–10 | 6–12 | 三幕，單一戲劇問題 | 精簡 | 2–4 |
| 20–30 分鐘 | 20–30 | 15–25 | 三幕＋一條 B 線 | — | 3–6 |
| 90–120 分鐘（長片） | 90–120 | 40–60 | 三幕八序列 | — | 5–10 |

短影音（≤90 秒）以 **3–8 秒為一個單位**切分，並把最強畫面放在前 3 秒。

## 2. 劇本格式規範

```
S01　內・老家廚房・夜

　　流理台上兩副碗筷。阿明站著吃，沒開燈。
　　冰箱嗡嗡響。他把其中一副碗筷推到旁邊，又推回原位。

　　　　　　　　阿　明
　　　　　（對著沒有人的方向）
　　　　　湯我熱了。

　　姊姊在門口，沒進來。
```

- **場次標題**：`S編號　內/外・地點・時間`。時間只用「日／夜／黃昏／清晨」。
- **動作行**：現在式、第三人稱、只寫拍得到的東西。
- **角色名**：置中或明顯縮排，全劇統一。
- **括號指示**：僅在語氣會被誤讀時使用，一場最多一兩個。
- **轉場**：預設不寫（`CUT TO:` 只在有敘事意圖時出現）。
- **不寫鏡頭指示**（景別／運鏡屬於導演），除非鏡頭本身即敘事手段。

## 3. 動作行寫法

| ✗ | ✓ |
|---|---|
| 他難過地看著她。 | 他看著她，然後低頭把袖口的線頭拉掉。 |
| 房間冰冷而空洞。 | 房間只有一張床墊。牆上有四個釘孔。 |
| 她想起了童年。 | 她的手停在門把上。 |

規則：
- **一段 3–4 行以內**，超過就分段。
- 禁止情緒形容詞（難過地／緊張地／開心地）。
- 禁止寫角色的心理活動、回憶、內心話。
- 道具要**具體到型號等級**的具體（不是「一個舊物件」，是「一支沒水的鋼筆」）。

## 4. 對白格式

- 語言依立項設定（國語為主，可摻台語；台語台詞後可用括號附國語意思）。
- 一句台詞盡量不超過兩行；長獨白必須有戲劇理由。
- 沉默寫成動作行：`（她沒有回答。）` 或直接寫她做的事。
- 打斷用 `——`；殘句用 `……`。

## 5. 交付骨架（六區塊）

**依序輸出，不增不減。**

```
【立項確認】
Logline：一句話。
主題論證：〔X〕必須以〔Y〕為代價。
規格：〔長度〕／〔場次數〕／〔角色數〕／〔場景數〕
未指定項採預設：……（沒有就省略此行）

【人物】
角色名（年齡・身分）｜想要：…… ｜害怕：…… ｜聲口：……
（每角一行，3–5 行）

【場次表】
S01｜場景｜這場在做什麼｜結果（＋/－）
（每場一行）

【劇本】
（標準格式全文）

【修訂紀錄】
・結構：……
・台詞：……
・假設：……
（上限三行）

【下一步】
一行。可建議：接 shot-script-director 轉分鏡／接 script-doctor-architect 做結構診斷／指定某場重寫。
```

**輸出禁令**：不寫問候語、不寫「希望你喜歡」、不在【下一步】以外再問使用者要不要修改、不展示內部稿次。

## 6. 範例片段

【人物】區塊示範：

```
陳阿明（38・水電工）｜想要：拿回母親留下的存摺 ｜害怕：被證明自己才是那個不孝的 ｜聲口：短句、愛用反問、講台語時才說真話
陳淑芬（45・姊姊）｜想要：把老家原封不動留著 ｜害怕：弟弟終究會消失 ｜聲口：長句、迂迴、一直在講別的事
```

【場次表】區塊示範：

```
S01｜內・老家廚房・夜｜阿明想開口要存摺，先幫姊姊熱湯｜沒開口（－）
S02｜外・老家門口・夜｜姊姊丟出鑰匙要他自己去拿｜拿到鑰匙，姊姊不再說話（＋轉－）
```
