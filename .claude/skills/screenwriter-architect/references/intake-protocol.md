## 0. 選題鐵則

1. **一次問完**：所有問題放在同一則訊息，不得分多輪追問。
2. **上限 8 題**：三組都要覆蓋（設定 ≥2、劇情 ≥2、長度 ≥1）。寧可少問，不可疲勞轟炸。
3. **只問會改變劇本的題**：brief 已經回答的、可由類型慣例安全推定的，一律不問。
4. **長度題永遠要問或確認**：長度決定場次數、幕結構、台詞量、預算，不能靠猜。
5. **每題附 ✔推薦**：使用者必須能只回「全部照推薦」就過關。
6. **選項要有戲劇差異**：ABCD 四個選項必須導向明顯不同的故事，不是同義詞換句話說。
7. **未答的題一律採預設，不得回頭再問。**

## 1. A 組：設定問題

| 代號 | 問題 | 選項菜單（擇一改寫成 ABCD） |
|---|---|---|
| A1 | **主角是誰？**（年齡・職業・當下處境） | 由 brief 推 2 個具體人選＋1 個反直覺人選＋自填 |
| A2 | **他最想要的「具體東西」是什麼？** | 保住某物／得到某人的一句話／抵達某地／隱瞞某事 |
| A3 | **時空設定** | 當代都會／當代小鎮或鄉間／指定年代（如 1990s 台灣）／不指定（架空當代） |
| A4 | **類型與調性** | 寫實日常（溫而不甜）／黑色幽默／懸疑張力／溫情催淚 |
| A5 | **語言與在地質感** | 國語為主／國台語混雜（長輩講台語）／指定方言或外語／無所謂 |
| A6 | **人物編制** | 單主角獨角戲／雙人對戲（最省預算、最容易好看）／三人三角／群像 |

> A2 是隱藏的關鍵題。使用者常給「一個關於孤獨的故事」這種主題，卻沒給**目標**——沒有目標就沒有場次結構。若 brief 缺 A2，**必問**。

## 2. B 組：劇情問題

| 代號 | 問題 | 選項菜單 |
|---|---|---|
| B1 | **觸發事件**：什麼事打破了他的日常？ | 收到一個東西／某人回來了／某人消失了／期限突然出現 |
| B2 | **阻力來自哪裡？** | 一個具體的人／體制或規則／他自己的性格缺陷／時間不夠 |
| B3 | **結局取向** | 得到目標但失去更重要的／沒得到目標但看清了自己／兩者皆失（悲劇）／開放式不給答案 |
| B4 | **主題論證**：想讓觀眾走出來時相信什麼？ | 用「〔某事〕必須以〔某代價〕換取」的句式給 3 個候選＋自填 |
| B5 | **必須保留的素材** | 真實事件／指定台詞／指定畫面／品牌或課程訊息／無 |
| B6 | **情緒落點** | 釋然／不甘／溫暖但帶刺／冷靜的殘酷 |

> B3 與 B4 決定第三幕。若兩者都缺，優先問 B3（較具體，使用者好答），B4 用推薦值代填並在【立項確認】揭露。

## 3. C 組：長度問題

| 代號 | 問題 | 選項菜單 |
|---|---|---|
| C1 | **成品長度** | 15–30 秒／60–90 秒／3 分鐘／5–10 分鐘短片／20–30 分鐘／90 分鐘以上長片 |
| C2 | **用途與平台** | 社群短影音／品牌形象片／影展短片／教學示範素材／長片開發 |
| C3 | **製作限制** | 場景數上限、角色數上限、可否夜戲・雨戲・群演・車拍、預算級別（學生／獨立／商業） |
| C4 | **交付形式** | 完整劇本／分場大綱＋關鍵場次全寫／純故事大綱 |

> C1 沒問到就寫，等於自選長度——最常見的失敗。**C1 為必問題**（除非 brief 明確指定）。
> C3 未答時採保守預設（場景 ≤3、角色 ≤3、日戲內景為主），並在【立項確認】揭露。

## 4. 輸出格式

```
【我讀到的】<一句話覆述使用者的點子，證明理解，並指出目前最大的空缺>

**A. 設定 — <題目>**
A1) 選項一
A2) 選項二 ✔推薦
A3) 選項三
A4) 選項四

**B. 劇情 — <題目>**
...

**C. 長度 — <題目>**
...

若要省事，直接回「全部照推薦」即可；也可以只回你在意的那幾題。
```

- 題目用短句，不寫說明段落。
- 每題最多 4 個選項，其中一個標 `✔推薦`。
- 可複選的題目在題目後標「（可複選）」。
- 全部問完就**停住**，不要接著開始寫劇本。

## 5. 預設值總表

使用者未回答時一律採用，並在【立項確認】用一行揭露「未指定項採預設：…」。

| 項目 | 預設值 |
|---|---|
| 時空 | 當代・台灣・都會邊緣 |
| 調性 | 寫實日常，溫而不甜，結尾留一點刺 |
| 人物編制 | 雙人對戲 + 1 個功能性配角 |
| 阻力 | 主角自己的性格缺陷（最省錢也最有深度） |
| 結局 | 沒得到目標，但看清了自己 |
| 語言 | 國語為主，長輩台詞可摻台語 |
| 長度 | 5 分鐘短片（約 5 頁，6–8 場） |
| 製作限制 | 場景 ≤3、角色 ≤3、日戲內景為主、無群演／無動物／無車拍 |
| 交付形式 | 完整劇本 |
