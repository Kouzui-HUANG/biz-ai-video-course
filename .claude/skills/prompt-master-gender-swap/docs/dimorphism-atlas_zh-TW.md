# 性別二態性圖譜 —— 解剖學參考

> 所有條目皆為**具有大幅重疊的統計性傾向**，而非規則。個體與族裔差異極大；許多男性有柔和骨相，許多女性有硬朗骨相。請把它們當作撰寫提示詞的方向性槓桿，絕不可用來斷言某位真實人物。

## 1. 骨骼（最難偽造，提示詞價值最高）

| 部位 | 女性傾向 | 男性傾向 |
|---|---|---|
| 額頭 | 垂直、圓潤，額結節明顯 | 向後傾斜，與鼻根銜接平直 |
| 眶上脊（眉骨） | 平坦，眉→眼窩過渡平順 | 明顯的橫向骨脊，眉下陰影深 |
| 眼窩 | 較大、較圓，上緣薄 | 較深、較方，眼睛更凹陷 |
| 顴骨 | 高位、偏前、圓潤蘋果狀 | 顴弓向外橫張，更寬更平 |
| 下顎角 | 鈍角（>125°），柔和收窄 | 接近 90°，咬肌附著處外擴 |
| 下巴 | 窄、短、圓或微尖 | 寬、高、方；有頦褶或頦裂 |
| 鼻部 | 鼻樑窄，鼻額凹陷深 | 鼻樑高／寬，鼻背直或帶駝峰，凹陷淺 |
| 中臉高度 | 較短；整體呈倒卵形／心形 | 較長；整體呈方形／長方形 |
| 眉與眼窩緣 | 眉在眼窩緣**之上**，帶弧度 | 眉**在緣上或之下**，平直 |

## 2. 軟組織

- **脂肪墊** —— 女性：淺層顴脂較厚，輪廓平滑連續。男性：脂肪較薄，咬肌與顴弓浮凸可見。
- **眼瞼露出** —— 女性：高弧眉下露出較多上瞼平台。男性：眉壓迫眼瞼，平台極少。
- **人中** —— 女性：短，靜態時露出較多上齒。男性：長。
- **唇紅** —— 女性：飽滿，唇珠明確。男性：薄，唇紅邊界平坦。
- **皮膚** —— 女性：較薄、毛孔細、透光感強。男性：較厚、毛孔粗、皮脂多、有鬍鬚區陰影。
- **髮際線** —— 女性：連續圓弧。男性：M 型顳部後退，裸露額頭面積更大。
- **表情紋** —— 男性：肌肉收縮幅度較大，抬頭紋與眉間紋更深。

## 3. 頸、肩、臂、軀幹 —— 胸上構圖的關鍵訊號

在任何胸上或更廣的裁切中，這些會**先於**臉部被讀取。可見時絕不可略過。

| 部位 | 女性傾向 | 男性傾向 |
|---|---|---|
| 頸部 | 更長更細，無喉結突起，胸鎖乳突肌柔和 | 更粗，看起來更短，喉結明顯，胸鎖乳突肌呈繩狀 |
| 斜方肌 | 頸到肩的坡度平緩 | 坡度陡且厚，頸根處有量體 |
| 肩寬 | 較窄；肩峰點柔和 | 較寬；肩峰方正有骨感 |
| 鎖骨 | 間距短、纖細，鎖骨上窩柔和 | 更長更粗，更接近水平 |
| 三角肌 | 小、圓潤平順，無肌理 | 大、方形肌帽，肌理明顯 |
| 上臂 | 纖細連續收窄，輪廓柔軟 | 較粗，二頭／三頭肌分界明顯 |
| 胸廓 | 較窄，腰線讀起來較高 | 較寬較深 |
| 胸部 | 自然適度的乳房輪廓 | 平坦寬闊的胸大肌平面 |
| 肩寬／頭寬比 | 約 2 個頭寬 | 約 2.5–3 個頭寬 |

## 4. 遮蔽對照表 —— 每種造型會讓什麼「出局」

搭配 SKILL.md §4 使用。若某特徵被遮蔽，它的子句就是浪費權重，**而且**會誘使模型更動遮蔽物去「露出」它。

| 造型 | 被遮蔽 | 仍完全可讀 |
|---|---|---|
| 齊眉齊劉海 | 額頭傾斜、髮際線、額結節 | 眉骨陰影、眉毛、下顎、下巴、頸部 |
| 斜瀏海 | 部分髮際線 | 大部分額頭、整個下半臉 |
| 長髮覆肩 | 外側肩線、斜方肌坡度 | 頸部、鎖骨、下顎 |
| 頭髮全部綁起 | 無 | 全部 |
| 高領／立領 | 頸部、喉結、鎖骨、胸部 | 完整臉部、下顎輪廓 |
| 細肩帶／露肩上衣 | 胸部以上無遮蔽 | 肩、鎖骨、斜方肌、三角肌、手臂 |
| 頭肩緊裁切 | 手臂、胸部、胸廓 | 臉、頸、肩頭 |
| 僅臉部特寫裁切 | 所有身體訊號 | 僅臉部 —— 第 1／2／4／6 級要用力推 |
| 保留鬍鬚 | 膚質區、下巴輪廓 | 眉、額、顴、頸 |
| 眼鏡 | 部分眉骨陰影判讀 | 下顎、下巴、唇、頸 |

## 5. 方向專屬陷阱

**男→女**
- 只去掉鬍青會讀成「刮了鬍子的男人」，不是女人 —— 必須由第 1、2 級領頭。
- 未經要求不要收窄鼻子；鼻子是最高等級的身分錨點，收窄它是最快丟失神似度的方法。
- 在任何胸上裁切中，只加長髮而不改肩線，會讀成戴假髮的男人。
- 加妝是**另一個**請求 —— 未經要求不要加（那屬於 `prompt-master-makeup`）。

**女→男**
- 只加鬍子會讀成戲服；變化必須由眉骨與下顎承擔。
- 只方化下顎卻不壓低眉毛，臉仍會讀成女性。
- 剪短髮通常會露出髮際線 —— M 型後退因此成為新增的可用權重（遮蔽的反向操作）。
- 不要自動把主體變老；男性化與年齡是彼此獨立的軸。

**→ 中性**
- 不要把每個特徵都取平均 —— 那會產生一張乏味的臉。把第 1、2 級強制推到中點，其餘維持中性。
- 頸部保持纖細但不柔弱；頸部在兩個方向都是破綻所在。
- 中性造型（髮型、服裝）是**最弱**的槓桿；放在最後陳述，絕不當作主要機制。
