## 1. 證據強度 — 先讀這段

Meta 從未公佈過排序權重。誠實校準每個主張，**不要把江湖傳說講成定律**。

| 主張 | 強度 |
|---|---|
| 存在兩個分發池（連結／非連結推薦） | **有官方文件** — Meta 公開描述過推薦驅動的分發 |
| 本體放外連結會壓制觸及 | **強觀察** — 業界數據高度一致，但未被官方確認為懲罰機制 |
| 點數 讚 1／心情 5／留言・分享 30 | **歷史外洩資料** — 2021 年揭露的 2018 年 MSI 框架。方向可用，數字已過時。**絕不能當成現行事實引用。** |
| 憤怒心情被降權至 0 | **有報導**（約 2020 年，同一批外洩資料脈絡） |
| 追蹤轉換是排序輸入 | **推論，非官方文件** — 從系統行為反推：Meta 把單篇追蹤歸因做成創作者後台的頭條指標，且發現式引擎普遍會建模這個。YouTube 已確認（訂閱轉換），FB 未確認。 |
| 負面訊號（隱藏／取消追蹤／檢舉）帶重度負權重 | **強觀察** |

**原則：** 使用者問「為什麼」時，要說明這個主張位於哪一層。一個很有自信但錯誤的機制，會產出很有自信但錯誤的文案。

## 2. 兩個流量池

觸及來自兩個地方，而它們的行為完全不同：

- **連結內容（connected）** — 發給既有追蹤者。現在只佔觸及的*少數*。
- **非連結推薦（unconnected）** — AI 推薦給陌生人。自 FB 約 2022 年轉向發現式動態牆後，這才是主要成長引擎。

**典型流程：** 新貼文先發給一小撮活躍追蹤者 → 在那裡的表現決定它能不能進入推薦池。

寫作者必須內化的兩個推論：

1. **第一批是測試，不是受眾。** 貼文裡的每一個設計，都是在為通過這道關卡最佳化。
2. **追蹤者品質 ＞ 追蹤者數量。** 抽獎粉、互追粉、買來的粉會稀釋測試樣本，讓貼文在第一關就死掉。5,000 個真的會讀的人，勝過 50,000 個不會讀的——後者這個數字是在主動傷害你。

**絕對不要告訴使用者「追蹤者數量驅動觸及」**。現在大致上已經不是了。

## 3. 訊號權重階梯

大致依權重與資訊量遞增。真正重要的規律是：**行為成本 ↑ → 雜訊 ↓ → 訊號價值 ↑。**

| 訊號 | 它實際上在說什麼 |
|---|---|
| 讚 | 「我不討厭這個」— 廉價、一天幾十個、資訊量近乎零 |
| 心情（愛心／哈／哇） | 弱的情緒確認 |
| 停留時間／點「顯示更多」 | 鉤子成功了。安靜但真實。 |
| 留言 | 投入了心力；同時開出第二個互動場 |
| 儲存 | 高 — 隱含未來效用；也拉高停留時間 |
| 分享 | 高 — 見 §4，它是四種訊號共用一個名字 |
| **追蹤轉換** | **最高 — 唯一的前瞻性訊號（§5）** |

**寫作者的翻譯：**
- 按讚 ≈「我不討厭這個」
- 分享 ≈「這個能代表我」← 注意：這是關於*分享者*，不是關於你
- 追蹤 ≈「我押注你未來還會產出這種東西」

## 4. 分享 — 這是四種訊號，不是一個動作

要哪一層就設計哪一層，它們不能互相替代。

| 層級 | 權重 | 原因 |
|---|---|---|
| 純轉發（無文字） | 最低 | 讀起來像反射動作；沒有產生新內容或對話 |
| 加註文字轉發 | 較高 | 分享者投入了創作成本；他的文字會在他自己的圈子裡**開出第二個留言串** |
| 分享到社團 | 高，且**跨池** | 把貼文送進你原本進不去的封閉流量池；在那裡的互動會回饋給原貼文 |
| **私訊分享（Messenger／限時動態）** | **最高，且看不見** | 願意直接傳給一個指名的人，是最強的認可。它是暗流量——你在後台永遠看不到，只會發現觸及莫名其妙變好。 |

**核心機制：**

> 人不會為了幫你而分享，人只會為了表達自己而分享。分享是社交貨幣。

所以貼文必須讓分享者顯得聰明、有品味，或有同理心——**是在他自己的觀眾面前**。

**每一次都要問的設計問題：**「他轉發這篇的時候，會在上面加什麼評論？」如果你答不出他會打的字，就代表你沒給他立場，他不會分享。重寫。

各層級的觸發設計：
- 加註轉發 → 給一個**鮮明立場**，值得認同或值得吵
- 截圖分享 → 埋一句**沒有上下文也成立的金句**
- 社團分享 → 對一個**可指認的社群**有具體實用性
- 私訊分享 → **在貼文裡點名收件人**：「這篇傳給那個一直說要做但拖了半年的朋友」——效果異常好，且買到的是最高權重那一層

## 5. 追蹤轉換 — 唯一的前瞻性訊號

單篇貼文帶來的新追蹤。可得訊號中價值最高的，理由有四個各自獨立：

**1. 它評價的對象不同。** 讚／留言／分享評價的是*這篇貼文* → 影響這篇的觸及。追蹤評價的是*作者* → 影響這篇**加上你帳號的長期基準分**。收益是複利的，不是單次的。

**2. 它稀缺，所以帶資訊量。** 一天幾十個讚，對比一*年*可能才幾十次追蹤。高行為成本＝低雜訊。

**3. 它是唯一對未來下的注。** 其他訊號都是對已消費內容的事後評價。追蹤是讀者自己做的*預測*：好東西還會有。對一個要決定「該不該繼續分發這個帳號」的系統來說，這是它能拿到的最直接答案。

**4. 在推薦池裡它沒有社交雜訊。** 陌生人對你零社交義務。朋友的讚被人情汙染；陌生人的追蹤是純粹的內容價值判斷。這就是為什麼追蹤轉換*特別*主宰非連結推薦池——而成長就住在那裡。

### 它是「率」，不是「數」

| 貼文 | 判讀 |
|---|---|
| 100 追蹤／1,000,000 觸及 | 糟 |
| 100 追蹤／10,000 觸及 | 極好 |

**反直覺的推論——相關時就寫進「訊號設計說明」：**

> 一篇 50 萬觸及、0 追蹤的爆文，對帳號長期是負面的。

它在告訴系統：*這個帳號能吸引點擊，但留不住任何人。* 跟 YouTube 高點閱／低訂閱是同一個陷阱。帳號會被歸檔成一次性刺激來源，而不是值得持續分發的創作者。

### 追蹤轉換是「兩段」漏斗

大部分人只最佳化第一段，然後想不通為什麼爆文一個粉都沒漲。

```
貼文 → 點頭像／名字 → 個人檔案 → 追蹤
                        ↑ 真正的轉換點
```

陌生人點進個人檔案，是為了回答一個問題：**「這人是不是穩定產出這種東西？」**

- 置頂＋最近三篇貼文實質上*決定*了轉換率——頂上掛著三個月前的活動宣傳，這個數字直接歸零，不管貼文寫得多好。
- 簡介要回答「追蹤你會得到什麼」，不是「你是誰」。
- 主題一致性不只是給人看的——推薦系統必須能歸類你的主題叢集，才知道要推給誰。今天 AI、明天早餐，等於每篇都從零開始。

拉高轉換率的貼文層級槓桿——全部都在講同一件事，**證明還有下一篇**：
- 序列標示：「AI 影片實驗第 7 天」——他知道第 8 天存在，追蹤才有意義
- **具體**預告下一篇的內容——勝過任何形式的求追蹤（求追蹤毫無作用）。模糊的預告（「下次聊更多」）同樣毫無作用——要點名內容。
- 展現產能而非靈感——讓人相信這不是你這輩子最好的一篇

## 6. 負面訊號

隱藏貼文／取消追蹤／檢舉是**負權重且很重**——一次可以抵掉很多次正向，而且傷害會往前帶到你接下來每一篇的初始觸及。

這正是索取型互動（「留言『要』我私訊你」）是陷阱的原因：短期互動數字漂亮，但一旦讀者感覺被套路，你買到的是取消追蹤。在任何長於一週的時間尺度上都是淨虧損。

其他會產生負面訊號的：兌現不了的標題黨、還沒給價值就開賣、發離題內容、釣互動的措辭。

## 7. 分享型 vs 追蹤型 — 結構性衝突

兩者往相反方向拉。這是本檔最重要的一個策略事實。

| | 分享型 | 追蹤型 |
|---|---|---|
| 內容 | 迷因、情緒、爭議、時事 | 專業、系列、獨特觀點 |
| 分享率 | 高 | 低—中 |
| 追蹤轉換 | **低** | **高** |
| 為什麼 | 人分享是為了表達自己——那個動作沒在講你 | 讀者認可的是作者，不是這一則 |
| 失效模式 | 跑步機：每篇都要重新爆一次，帳號沒有底線 | 天花板低：好內容沒人看見 |

**分享讓這篇活，追蹤讓下一篇更容易活。**

內容規劃需要兩者搭配成節奏——但*任何單一貼文*都必須選一個。一篇同時最佳化兩者的貼文，會兩個都做不到。

## 8. 這對帳號經營代表什麼

相關時值得告訴使用者的兩句話：

- **追蹤轉換率是唯一誠實的指標。** 觸及和讚都會騙你——它們可以一邊上升、帳號一邊變弱。追蹤轉換率是唯一能告訴你帳號在複利、還是只是在燃燒注意力的數字。
- **買粉和抽獎粉是負資產**，不是中性的：它們毒害的是那個決定任何貼文能否進入推薦池的初始測試批。
