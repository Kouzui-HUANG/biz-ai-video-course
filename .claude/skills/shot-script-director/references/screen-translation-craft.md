## 0. 核心心法：意義活在縫隙裡

電影的意義大量地活在「縫隙」裡，而不是活在被說出來的東西上。潛台詞活在台詞與真實意圖的縫隙、反諷活在畫面與聲音的縫隙、戲劇性懸念活在觀眾所知與角色所知的縫隙、情緒的外化活在內在狀態與一個不相稱的外部動作的縫隙。

散文的本能是「告知」，電影的本能常常是「保留」，把推論的工作留給觀眾去做。整個轉譯過程中最關鍵的一次心態翻轉，是從**「我要怎麼把 X 傳達出去」**變成**「我最少要露出多少，就能讓觀眾自己把 X 建構起來」**——而這個「露多少、留多少」的拿捏本身就是表達手段。

把這句話放在心裡，下面每一項能力才不會散成一張清單。四個工位：**向上讀 → 核心轉碼 → 向下實現 → 統攝全局**；尺度切換穿插在每一層。

## 1. 向上讀：把散文剝到承重層

**功能性閱讀。** 最先要練成的反射：看任何一段文字，不問它「說了什麼」，而問它「在做什麼」。同一句話可能在做鋪陳資訊、建立氛圍、推進因果、揭示性格、埋伏筆、或純粹是作者的修辭快感——功能不同，落地手段就完全不同。
- 診斷句：**「如果把這段刪掉，什麼會斷？」** 斷不掉的，多半是氛圍或主題，就不該硬拍成鏡頭，要靠別的層面滲進去；一刪就斷的，才是承重的戲劇材料。
- 失敗模式：被漂亮的句子勾住，把「寫得好」誤當成「該拍」。

**結構透視。** 在血肉底下看見戲劇骨架。散文的組織邏輯和戲劇的組織邏輯是兩套：文章可按論證、聯想、時間之流、或情緒漲落來組織，而戲劇只認一種脊椎——**欲望、阻礙、轉折、後果**。透視就是抽掉源文本的表層邏輯，重新問：誰要什麼？什麼擋著？賭注是什麼？賭注有沒有一路加碼？很多散文根本沒有這條脊椎（它靠別的東西撐），這時殘酷的事實是：這裡沒有現成的戲，你得自己長一條出來。

**故事與論述的分離。** 把「事件的因果鏈本身」和「作者講述它的方式」拆開（敘事學的 fabula 與 syuzhet）。散文的順序、視角、詳略，往往是「講述」層的選擇，不是「事件」層的事實。要先把事件還原成一條中性時間線，才有辦法重新決定：在銀幕上用什麼順序、從誰的眼睛、以什麼詳略重講一遍。混淆兩層的人，會把作者的敘述腔調當成故事本身照抄，拍出一堆其實是「文章的講法」而非「故事的事件」的鏡頭。

## 2. 核心轉碼：把內在／抽象重新編碼成外部徵候

原子操作是「**為觀眾的解碼器而編碼**」。三把更細的刀法：

**外化（Externalization）。**
- **客觀對應物（艾略特）**：要傳達某種情緒，唯一的辦法是找到一組物件、一個情境、一連串事件，讓它們成為那個情緒的「公式」，觀眾一看到公式就自動生出那個情緒。改編者永遠在替每一個內在狀態求它的客觀對應物。
- **一個內在狀態至少有三個可拍切面——成因／症狀／後果。**「他很內疚」：可拍導致內疚的那件事（成因）、內疚外顯的坐立難安（症狀）、或內疚驅使他去做的補償行為（後果）。哪個最有口才、最不落言詮，每次都要重選；**通常「後果」——狀態逼出的一個動作——最有力，因為它同時是情緒也是情節。**
- **分辨「圖解」與「體現」**：角色一邊說「我好難過」一邊擺出難過的臉，那是**圖解**，把散文的直述換皮照搬；真正的**體現**，是讓難過從一個「不相稱」的動作裡漏出來（她笑著把對方的東西一件件收進紙箱），意義就落在那道縫隙裡。

**具體化（Concretization）。** 攝影機沒有「一般的鳥」可拍，只能拍這一隻、這一盤、這一件。抽象名詞被逼著長出一個特定殊相，而你選的那個殊相會反過來承載意義——同樣是「父親留下的東西」，選一支老鋼筆、一件工作圍裙、還是一把生鏽的鑰匙，講的是完全不同的父子關係。這既是暴政也是機會：暴政在於被迫做出源文本沒替你做的無數具體決定，機會在於每一個具體物都是一次額外的表意。

**因果焊接（Causal Welding）。** 改編不只是刪減，常常是增生。散文可把兩件事並置而不主張因果，讀者自會腦補；戲劇的因果鏈卻必須在銀幕上「感覺起來」是被動機推著走的。於是你經常得無中生有——補一場戲、補一個動機、補一個過渡節拍——把原著跳接的因果焊起來，否則觀眾會覺得角色的轉變是空降的。
- 判斷點：**從 A 狀態到 B 狀態，中間那個「因為所以」有沒有在畫面上被建立過？** 沒有的話，缺的那一環就是你要生出來的新材料。

## 3. 向下實現：在膠片的具體語彙裡重蓋一遍

**空間想像。** 戲一定得發生在某個具體空間，而空間本身就是表意工具：房間的地理、人與人的距離、門檻與遮擋、什麼進了畫框什麼被擋在外面，都在說話。替每一場戲發明一個既服務戲劇功能、又給攝影機和演員留出走位餘地的空間。
- 疏離 → 用前景物件把兩人隔開、用景深把他們推遠。
- 權力關係 → 用高低、用誰背對門、用誰佔據畫面的量來寫。

**潛台詞設計（Subtext）。** 說出口的和真正想要的之間的落差。散文裡敘述者可直接告訴你潛台詞，銀幕上它只能活在台詞與行為的縫隙。寫對白的心法不是「讓角色把重點說清楚」，而是**讓表面的交談去掩護底下真正的交易**——兩個人明明在談要不要留下來吃飯，其實在談要不要原諒彼此。
- 診斷點：**這段對白的「字面內容」和「真正在角力的東西」是不是同一件事？** 如果是，這段對白多半太平、太滿。

**時間的重構。** 最被低估、也最需要專門能力的一塊。散文對時間有全權：可壓縮（「那年冬天他們漸漸疏遠」）、可拉伸、可省略、可概述、可寫「每天早上他都會……」這種反覆常態。電影卻以真實時長運行，你必須逐一換算（對應敘事學的順序、時距、頻率三組選擇）：
- **概述**（一段話帶過幾個月）→ 時間跳接、蒙太奇、字幕卡、或挑一個代表性場景來承載。
- **反覆／習慣**（發生過很多次）→ 蒙太奇動機、或一個「代表全部」的單一實例。
- **省略** → 決定跳過什麼、以及讓觀眾怎麼察覺被跳過了。
- **大槓桿**：呈現順序可以不等於事件順序——為了效果重排時序（先給結果再倒回成因）。
- 一場戲拉多長、剪多快，其快慢本身就是意義，不是中性的容器。

**視點與資訊經濟。** 兩件綁在一起的事：
- **視點**：把散文的敘事人稱換算成攝影機的光學視點（全知、第一人稱、乃至最難搞的自由間接文體——敘述者聲音與角色內心融在一起，電影只能用主觀鏡頭、聲音設計、旁白去近似而非等值）。
- **資訊經濟**：在每一刻，觀眾知道什麼、比角色多知還是少知、你藏什麼露什麼。希區考克「桌下炸彈」講得最清楚——同一顆炸彈，觀眾不知道，爆炸只給三秒**驚嚇（surprise）**；觀眾先知道而桌上的人不知道，這頓飯的每一秒都變成煎熬的**懸念（suspense）**。散文常自然地把資訊平均攤給讀者，改編時你得刻意重新分配「誰在什麼時候知道」，把它當成節奏與張力的引擎。

## 4. 統攝全局：監督整個轉換的元能力

**尺度切換。** 各層決定互相約束，所以要能在「**全片 → 幕 → 段落 → 場 → 節拍 → 鏡頭**」之間流暢上下移動——遞迴、階層式的思考，而且各層之間有個美麗的自相似：**欲望—阻礙—轉折—後果**這個結構會在每一個尺度上重演一次。一場戲不只要在本地成立，還得推進全片的弧線；只在本地好看、卻不推進大弧的戲，就是該被砍的候選。

**媒介等效與補償。** 這個轉碼是有損的，要一直對「各媒介的強項」有清醒的帳：
- 散文強在**內在性、反諷、時間的自由、直接陳述**。
- 電影強在**臨場感、同時性、一張臉上說不出口的東西、真實時長、同一畫面裡並置兩件事**。
- 所以不逐字搬，而是找等效物、做補償——永遠問「這句話在做什麼，用什麼影像手段能達到同樣效果」。更高一階的意識是：不要只想著補回損失，要主動去用**只有電影做得到的事**，把它當成淨賺。

**選擇與捨棄。** 改編是減法多過翻譯。素材永遠多過一部片裝得下，你得有膽識砍、壓、併：把幾個角色併成一個複合角色，把好幾場戲併成一場去做好幾件事，守住「**一場戲盡量身兼多職**」的經濟原則。最難的是砍掉自己（或原著）鍾愛、但不服務脊椎的東西。

**調性保存。** 上面全部換算都做對了，還可能整體走味。源文本的調性——它的冷、它的暖、它的反諷距離、它的抒情濃度——得在另一套媒介的文法裡被重新實現，而電影的調性不寫在台詞裡，寫在**剪接的呼吸、鏡頭與被攝物的距離、聲音與畫面的關係**裡。這是最後一道、也最難言傳的校驗。

## 5. 思考進程（螺旋式，不是直線）

這不是一條走完就好的流水線，而是一個**下沉—折返的螺旋**。你會從高層一路往具體下潛，在某個鏡頭層撞到問題，發現它其實是分場甚至分幕沒站住，於是折回上層改，再下潛一次。下面的編號是邏輯先後，實作上永遠來回。

1. **診斷與定調（讀出引擎）。** 先抓主題、故事脊椎、貫穿全片的中心戲劇問題、源文本的類型與調性。讀的是驅動力，不是字句。核心問題：*這故事到底在問什麼？情緒溫度幾度？*
2. **分離故事與論述。** 把中性時間線從作者講述方式裡拆出來，同時做功能性閱讀，把「可戲劇化的材料」和「只能提示的東西（說明、氛圍、主題）」分兩堆。核心問題：*哪些能演？哪些一演就假、只能靠滲透？*
3. **選擇、重組、找出貫串線。** 決定留什麼、砍什麼、併什麼；併角色、併場景；找出那條把散落材料串成一條的主軸。核心問題：*如果只能保住一條線，是哪一條？*
4. **立骨架、分幕。** 把選出的材料排成一條戲劇弧線，定轉捩點與段落結構。三幕只是慣例不是鐵律，真正要定的是「張力的形狀」與加碼的節奏。核心問題：*賭注在哪裡升級？大的轉折落在哪幾個點？*
5. **重構時間。** 分場之前先把時間軸決定好：哪裡壓縮成蒙太奇、哪裡用省略跳過、呈現順序要不要重排、整體節奏疏密。核心問題：*故事時間怎麼映射到銀幕時間？要不要動它的順序？*
6. **分場。** 把每段戲切成離散的場（一場＝時間＋地點的連續單位）。替每場指定單一功能與一個**狀態差**（這場結束時，什麼變了？），套用「**遲進早出**」（晚一點進、早一點出），把場與場排出因果的 build 與節奏。核心問題：*這場開始與結束之間，狀態有沒有明確改變？沒有的話它為什麼存在？*
7. **設計場的內部。** 逐場鋪：誰要什麼、被什麼擋住、如何翻轉、潛台詞是什麼；同時把抽象落成具體——這場發生在哪個具體空間、翻轉靠哪個具體動作或物件觸發、對白如何用表面掩護底下的交易。在此決定這場**需不需要對白、哪些用「說」哪些用「做」**，順序是**先定動作與潛台詞、台詞最後才落下**（台詞刀法見 `dialogue-craft.md`）。**務必讓原諒／和解／崩潰這類內在事件發生在「一個動作」裡而不是「一句宣告」裡。** 核心問題：*這場的重量能不能不靠台詞、只靠一個動作就落地？*
8. **視覺化成鏡頭。** 把每場拆成鏡頭：攝影機看什麼、鏡頭順序、景別、運動、剪接節奏，並定下這場的視點與資訊分配。把戲劇重音對映到視覺文法——**情緒高點常給近景讓觀眾讀臉，全景用來建立或孤立，轉折的那一刻放慢甚至停頓。** 視覺化完成後、進入多尺度回讀前，先插一道**台詞層校驗**（見 `dialogue-craft.md` §4）。核心問題：*這場的戲劇重音在哪個瞬間？景別與剪接有沒有把強調放在同一個地方？*
9. **多尺度回讀校驗。** 退回每一層各檢查一遍：每場有沒有掙到位置、全片弧線站不站得住、有沒有冗餘、資訊釋放時機準不準、節奏對不對、連戲有沒有問題、整體調性有沒有走味；**把角色名全遮掉，還認得出誰在說話嗎**（認不出＝聲口沒分化）？核心問題：*如果把這場（這鏡）拿掉，觀眾會少掉什麼不可替代的東西？*
10. **迭代。** 任何一層的修改都會逼其他層重來，回到相應步驟再下沉一次，直到各尺度彼此扣得住。

## 6. 完整範例走查

### 範例 A：抽象＋內在＋時間壓縮 —「多年後，他終於原諒了父親。」
這句同時是內在的、時間被壓縮的、抽象的，照字面無法拍。
- **功能性讀**：它是「一段長期怨懟的解除」，是角色弧線的閉合點、全片的那個大轉折——所以承重，必須被拍，且要拍得夠份量。
- **外化**：「原諒」拍不了，只能拍「可被觀眾推論為原諒」的外顯行為。選「**後果**」切面最有力——不拍他宣布原諒，拍原諒逼出的一個動作。
- **具體化**：需要一個承重的具體場景與物件——父親病榻旁、老家的廚房、一件父親一直想交還而他一直拒收的舊物？選哪個物件，就決定了這對父子究竟為什麼失和。
- **因果焊接**：如果前面沒建立過他們為何決裂、他這些年扛著什麼，這個原諒會像空降；往回檢查，缺的那一環要在前面補出來。
- **場的內部**：場開始是僵硬的距離，某個具體動作觸發翻轉，場結束時距離消解——讓原諒發生在動作裡（他替父親做了一件一直拒絕做的小事，或收下父親遞過來的東西），不靠任何一句「我原諒你」。潛台詞：兩人嘴上也許在講一件完全無關的瑣事。
- **鏡頭層**：阻隔階段用帶關係的雙人鏡、或隔著前景物件的構圖寫疏離；翻轉那一刻給近景，讓觀眾自己從臉上讀出鬆動；剪接在轉折點放慢、甚至停在一個靜默的鏡頭上，把推論的空間讓給觀眾。
- 一句抽象的話，就這樣一路串出空間、物件、動作、場的轉折、景別、剪接節奏——每個決定都是把「原諒」這個內在狀態，重新編碼成觀眾能解讀的外部徵候。

### 範例 B：時間重構＋保留 —「那年冬天，他們漸漸疏遠了。」
這不是一個事件，是一段過程，硬塞進單一場戲會失真。兩條路：
- **路一（蒙太奇）**：用蒙太奇串起遞減的動機——同一張餐桌，話越來越少、距離越來越開。
- **路二（更省，通常更好）**：只給一頭一尾兩場戲（一場親密、一場冷淡），把中間的侵蝕整段省略掉，讓觀眾在那道縫隙裡自己把「怎麼走到這步」補完。
- 第二種往往更好，正因為它不告知、只保留，把疏遠的重量交給觀眾的推論去承擔——這就是「電影在縫隙裡思考」。

## 收束：最硬的核心
這個對映是**多對多而且有損的**。同一句話有無數種合法的具體化，功力在於從中選出**最能保存、甚至放大源文本核心效果**的那一個，同時用上只有電影才做得到的東西——並始終記得：你不是在把意義「填滿」給觀眾，而是在**精確地控制要露出多少、留多少縫隙，讓觀眾自己走進來把它建構完成**。
